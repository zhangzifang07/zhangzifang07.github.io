## 2、demo工程搭建

- 修改子项目的(子项目名.gradle)文件，其他的不用动

```javascript
description = "ruihu"  
  
dependencies {  
    // 子项目私有依赖添加  
}  
  
sourceSets {  
    main {  
        java {  
            include 'com/weaver/**' // 只包含自己包下的 java        }  
  
        resources {  
            // 打jar排除resources目录下所有的文件  
            exclude '**'  
        }  
    }}
}
jar {  
    archiveBaseName.set('secondev-e10-ruihu')  
    archiveVersion.set('')    // 不显示版本号  

}
```

## 3、手动拉取JAR包

- 应用服务器找到二开服务位置

```Properties files
#找到二开服务位置 HeapDumpPath
ps -ef|grep secondev

#进入目录
cd data/weaver/e10-server0/weaver-secondev-service/webapps/

#打包资源
tar -zcvf second.tar.gz ROOT/

zip -r sdev.zip ROOT/

#通过ftp工具进行下载
```

- WEB-INF/lib目录下的所有 jar 拷贝至 IDEA 项目secDevLib目录下
