# 一、Safari浏览器使用

> 符号约定：⌘ = Command，⌥ = Option，⇧ = Shift，⌃ = Control。
> 以下快捷键整理自 Apple 官方文档，不同键盘布局下个别键位可能有差异，如果快捷键失灵，去菜单栏里看一眼对应的菜单项最保险。

## 1、窗口与标签页

| 操作                | 快捷键                       |
| ----------------- | ------------------------- |
| 新建标签页             | ⌘T                        |
| 重新打开最近关闭的标签页      | ⇧⌘T                       |
| 关闭当前标签页           | ⌘W                        |
| 关闭当前窗口            | ⇧⌘W                       |
| 新建窗口              | ⌘N                        |
| 新建「无痕浏览」窗口        | ⇧⌘N                       |
| 显示标签页概览           | ⇧⌘\                       |
| 切换到第 1~8 个标签页     | ⌘1 ~ ⌘8                   |
| 切换到最后一个标签页        | ⌘9                        |
| 切换到下一个 / 上一个标签页   | ⌃Tab / ⌃⇧Tab（或 ⇧⌘] / ⇧⌘[） |
| 关闭其他全部标签页，只保留当前这个 | ⌥ 点按该标签页上的关闭按钮            |

鼠标 / 触控板配合技巧：

- ⌘ 点按链接或书签：在新标签页中打开（后台打开，不切换过去）
- ⇧⌘ 点按链接或书签：在新标签页中打开，并立即切换为该标签页
- 在智能搜索栏输入内容后：⌘↩ 后台新标签页打开，⇧⌘↩ 新标签页打开并切换

## 2、页面导航

| 操作 | 快捷键 |
|------|--------|
| 后退 / 前进 | ⌘[ / ⌘] |
| 回到主页 | ⇧⌘H |
| 聚焦地址栏（智能搜索栏） | ⌘L |
| 刷新页面 | ⌘R |
| 停止载入 | Esc |
| 滚动到页首 / 页尾 | ⌘↑ / ⌘↓ |
| 向下 / 向上翻一页 | 空格 / ⇧空格 |
| 打印当前网页 | ⌘P |
| 打开 Safari 设置 | ⌘, |

小技巧：按住地址栏左侧的「后退 / 前进」按钮不放，会弹出最近访问过的历史列表（按名称排序）；按住 ⌥ 再点，则按网址排序。

## 3、页面查找与阅读

| 操作 | 快捷键 |
|------|--------|
| 页内查找 | ⌘F |
| 查找下一个 / 上一个 | ⌘G / ⇧⌘G |
| 打开阅读器（Reader） | ⇧⌘R |
| 退出阅读器 | Esc |
| 缩放网页内容 | ⌘+ / ⌘- |

| 添加当前页到阅读列表 | ⇧⌘D |
| Option 点按链接 | 直接下载链接指向的文件 |

## 4、书签、个人收藏与阅读列表

这三个是 Safari 里最容易混的三个功能，一句话概括：**书签是资料库，个人收藏是快捷启动栏，阅读列表是稍后读清单。**

### 三者的区别

| | 书签 | 个人收藏 | 阅读列表 |
| --- | --- | --- | --- |
| 定位 | 长期资料库，按文件夹归档 | 快捷启动栏，最快到达 | 稍后读的待阅队列 |
| 出现位置 | 书签边栏（⌃⌘1）、书签菜单 | 地址栏下方的收藏栏 + 起始页 | 阅读列表边栏（⌃⌘2） |
| 整理方式 | 多级文件夹 | 单层列表，宜少而精 | 按加入时间倒序，无需整理 |
| 离线阅读 | 不支持 | 不支持 | 支持（可离线存储网页） |
| 已读管理 | 无 | 无 | 未读 / 全部可切换，读完即删 |
| iCloud 同步 | 支持 | 支持 | 支持 |

需要特别注意：**个人收藏并不是独立功能，它本质上是书签的一个特殊位置**。⌘D 添加书签时位置选「个人收藏」，该站点就会出现在收藏栏和起始页，相当于把最常用的几个书签前置到了最快触达的位置。

### 使用场景

- **书签**：按主题建文件夹长期归档。比如「E10 开发」「OA 常用」「博客资源」，放官方文档、常用后台入口、工具站。判断标准：这个站点以后还会反复访问。
- **个人收藏**：只放每天必开的站点（OA 登录页、博客后台、GitHub、邮箱等），控制在 10 个以内，一屏放得下、不用想就能点到。
- **阅读列表**：刷到长文 / 教程但当下没空细看，⇧⌘D 扔进去，通勤或睡前按顺序清。支持离线保存——在侧边栏里 Control 点按条目选「离线存储」，或在「Safari 浏览器 > 设置 > 高级」里打开「自动存储文章以便离线阅读」，没网也能看。看完删掉，保持队列清爽。另外读到一篇文章底部继续滚动，会自动接着读列表里的下一篇。

### 常用操作

| 操作 | 快捷键 |
|------|--------|
| 添加书签（位置可选：个人收藏 / 其他文件夹） | ⌘D |
| 添加当前页到阅读列表 | ⇧⌘D |
| 添加链接网页到阅读列表 | ⇧ 点按链接 |
| 打开书签管理器（整理文件夹结构） | ⌥⌘B |
| 显示 / 隐藏书签边栏 | ⌃⌘1 |
| 显示 / 隐藏阅读列表边栏 | ⌃⌘2 |
| 显示 / 隐藏个人收藏栏 | ⇧⌘B |
| 一次打开收藏栏中某个文件夹内的全部书签 | ⌘ 点按该文件夹 |

小技巧：书签边栏打开后，可以用 ↑↓ 选择、空格打开、Return 重命名，基本可以纯键盘操作。

## 5、高频速查表

日常工作真正高频的就这 9 个，建议先记住：

| 快捷键     | 作用               |
| ------- | ---------------- |
| ⌘T      | 新建标签页            |
| ⌘W      | 关闭标签页            |
| ⇧⌘T     | 恢复刚关掉的标签页        |
| ⌃Tab    | 切换标签页            |
| ⌘1 ~ ⌘9 | 直达第 N 个（最后一个）标签页 |
| ⌘L      | 聚焦地址栏            |
| ⌘R      | 刷新页面             |
| ⌘[ / ⌘] | 后退 / 前进          |
| ⌘F      | 页内查找             |


另外记几个触控板手势，配合快捷键效率更高：双指左右滑动 = 后退 / 前进；双指捏合 = 缩放网页；双指点按 = 右键菜单。
