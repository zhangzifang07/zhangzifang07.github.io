# 第一章 摄影基础概览

这一章先建立摄影的“地图”。不用急着把每个参数都操作熟，只要先知道它们大概负责什么。

## 1.1 相机到底在做什么

一张照片，本质上是在记录光。

可以把相机理解成一个“接光的盒子”：

```text
世界里的光  ->  镜头收进来  ->  相机记录下来  ->  形成照片
```

相机最核心的任务，是控制照片：

```text
亮不亮
清不清楚
背景虚不虚
颜色准不准
主体是否突出
```

---

## 1.2 曝光三角：光圈、快门、ISO

照片的亮度主要由三件事决定：光圈、快门、ISO。

它们合起来叫“曝光三角”。

```text
          一张照片的亮度
                ▲
                │
      ┌─────────┼─────────┐
      │         │         │
    光圈       快门        ISO
  进多少光   进光多久    放大多少光
```

新手先记一句话：

```text
光圈管虚化，快门管动静，ISO 管画质。
```

### 1.2.1 光圈 Aperture

光圈可以理解为镜头里的“窗户”。

窗户越大，进光越多，背景越容易虚化。

```text
大光圈 F2.8              小光圈 F8 / F11

   ◉                         ●
进光多                    进光少
背景更虚                  背景更清楚
适合人像、弱光            适合风景、合影
```

一个容易反直觉的点：

```text
F 数字越小 = 光圈越大
F 数字越大 = 光圈越小
```

例如：

```text
F2.8  >  F4  >  F5.6  >  F8  >  F11
更大光圈                         更小光圈
更虚化                           更清晰
更亮                             更暗
```

你的腾龙 28-200mm 镜头上的 `F2.8-5.6` 表示：

```text
28mm 时，最大光圈约 F2.8
200mm 时，最大光圈约 F5.6
```

也就是说，变焦到更长焦时，最大光圈会变小一些。

### 1.2.2 快门 Shutter

快门可以理解为相机“睁眼”的时间。

快门越快，越能凝固动作；快门越慢，越容易拍糊，也更容易拍出拖影和流动感。

```text
快门快：1/1000s

适合人跑动、车经过、鸟飞等场景
画面更容易定住


快门慢：1/10s

手抖、人物移动、水流都容易产生拖影
画面更容易模糊
```

常用理解：

```text
1/1000s  很快：运动、动物、街头瞬间
1/250s   常用：走动的人、日常抓拍
1/125s   人像安全线
1/60s    勉强手持，容易糊
1/10s    很慢，通常需要稳定或三脚架
```

拍人时先记：

```text
人不动：至少 1/125s
人会动：尽量 1/250s 或更快
```

### 1.2.3 ISO

ISO 可以理解为相机的“亮度增益”。

ISO 越高，照片越亮，但噪点也可能越多。

```text
ISO 100             ISO 3200 / 6400

画质干净             画面更亮
细节更好             噪点更多
适合白天             适合夜晚、室内
```

简单参考：

```text
光线足够：ISO 100-400
室内/阴天：ISO 800-3200
夜晚：ISO 3200 以上也可以接受
```

新手不要过度害怕 ISO。照片稍微有噪点，通常比照片拍糊更好。

---

## 1.3 其他常见术语速览

这些术语后面会单独展开。现在先把名字和作用混个脸熟。

### 1.3.1 焦距 Focal Length

焦距就是镜头“看得宽还是看得远”。

```text
28mm        50mm        100mm        200mm
广          自然         拉近          很远
风景/环境    日常/街拍     人像/细节      特写/压缩
```

### 1.3.2 景深 Depth of Field

景深就是照片里“清楚的范围有多厚”。

```text
浅景深：主体清楚，背景虚
深景深：主体和背景都清楚
```

### 1.3.3 对焦 Focus

对焦就是告诉相机：照片里哪里必须清楚。

```text
对焦点在哪里，哪里就最清楚。
```

拍人时，最重要的是眼睛清楚。

```text
眼睛清楚 > 脸清楚 > 衣服清楚 > 背景清楚
```

### 1.3.4 白平衡 White Balance

白平衡控制照片颜色是偏冷、正常，还是偏暖。

```text
偏蓝                正常                偏黄
冷冷的              接近真实             暖暖的
```

新手阶段可以先使用：

```text
AWB 自动白平衡
```

### 1.3.5 RAW 和 JPEG

可以这样理解：

```text
JPEG：相机已经帮你处理好的照片
RAW：保留更多信息的数字底片
```

建议后续设置为：

```text
RAW + JPEG
```

这样既有能直接看的照片，也有以后可以认真修的底片。

### 1.3.6 曝光补偿 EV

曝光补偿是快速让照片整体更亮或更暗的功能。

```text
+0.7：亮一点
+1.0：更亮一点
-0.7：暗一点
-1.0：暗很多
```

图像理解：

```text
-1.0 EV        0 EV          +1.0 EV
偏暗           相机认为正常    偏亮
```

## 1.4 当前阶段小抄

```text
光圈 F      控制虚化和进光
快门 s      控制动作清楚还是模糊
ISO         控制亮度增益和噪点
焦距 mm     控制看得宽还是看得远
对焦 AF     控制哪里清楚
白平衡 WB   控制颜色冷暖
RAW/JPEG    控制照片后期空间
曝光补偿 EV 快速调整整体亮暗
```

三句核心口诀：

```text
想背景虚：大光圈 + 长焦 + 靠近主体 + 背景远
想不拍糊：快门要够快
想画质好：ISO 尽量低，但不要为了低 ISO 把照片拍糊
```

# 第二章 焦距：理解 28-200mm 镜头

这一章专门理解你的腾龙 28-200mm 镜头。

先记住一句话：

```text
焦距不是简单的“放大缩小”，而是在改变画面的感觉。
```

---

## 2.1 焦距是什么

焦距可以理解成“相机的视野宽窄”。

你的镜头是 `28-200mm`，表示它可以从 28mm 的广角变到 200mm 的长焦。

```text
28mm 广角：看得很宽

┌────────────────────────┐
│ 天空  建筑  路人  树  街道 │
│        拍进很多环境        │
└────────────────────────┘


200mm 长焦：看得很窄

┌──────────┐
│ 远处一个人 │
│ 或一个细节 │
└──────────┘
```

很多新手会以为变焦只是“把东西拉近”。其实不止如此。

焦距还会改变：

```text
空间感
背景大小
人物脸型
主体突出程度
照片氛围
```

---

## 2.2 28mm、50mm、100mm、200mm 分别适合什么

可以先这样记：

```text
28mm  -> 风景 / 环境 / 室内 / 多人合照
50mm  -> 日常 / 街拍 / 生活记录
100mm -> 人物 / 半身 / 特写 / 背景虚化
200mm -> 远处细节 / 舞台 / 建筑局部 / 压缩感
```

### 2.2.1 28mm：交代环境

`28mm` 适合拍“我在哪里”。

适合：

```text
风景
建筑
城市街道
室内
多人合照
旅行打卡
```

画面感觉：

```text
┌──────────────────────┐
│      天空和建筑        │
│   路   人   店铺   树   │
│        主体比较小       │
└──────────────────────┘
```

28mm 的重点：

```text
环境很重要，主体只是画面的一部分。
```

拍人时注意：

```text
不要离人太近，否则脸和身体容易被拉变形。
```

### 2.2.2 50mm：自然的日常视角

`50mm` 接近人眼日常观察的感觉。

适合：

```text
吃饭
朋友
街拍
咖啡馆
生活记录
半身照片
```

画面感觉：

```text
┌──────────────────┐
│      背景适中      │
│        人物        │
│      环境还在      │
└──────────────────┘
```

50mm 的重点：

```text
自然、不夸张、不压迫。
```

如果不知道用什么焦段，可以先用 50mm 附近。它像摄影里的“普通话”，不一定最惊艳，但很容易表达清楚。

### 2.2.3 100mm：人物更突出

`70-135mm` 是这支镜头非常值得练的范围。

适合：

```text
人像
宠物
花
食物
局部细节
街头抓拍
```

画面感觉：

```text
┌──────────────┐
│   背景变少     │
│    人更突出    │
│   虚化更明显   │
└──────────────┘
```

为什么 100mm 拍人更好看：

```text
28mm：脸容易变形，背景很多
50mm：自然
100mm：脸型更舒服，背景更柔和
200mm：主体很突出，背景被压缩
```

拍人时可以先记：

```text
好看人像 = 85-135mm + 离背景远一点 + 对焦眼睛
```

### 2.2.4 200mm：远处细节和压缩感

`200mm` 是长焦端，适合拍远处的主体和细节。

适合：

```text
舞台
远处的人
建筑细节
花草
街头瞬间
背景压缩感
```

画面感觉：

```text
相机        人                      背景
| -------- | -------------------- 楼/树/灯

200mm 拍出来：
人和背景看起来更近，背景更大、更满。
```

这叫“空间压缩”。

形象理解：

```text
28mm 拍一条路：
路很长，远处很远，空间感强

200mm 拍同一条路：
远处的车、楼、人好像都被压到一起
画面更紧凑，更有电影感
```

---

## 2.3 同一个主体，不同焦距讲不同故事

同样拍一个人，不同焦距的表达不同：

```text
28mm：人在环境里
适合旅行照、街头照、人在某个地方的故事

50mm：人和眼前所见差不多
适合自然、生活化记录

100mm：人是主角
适合更好看、更干净的人像

200mm：人被从背景中摘出来
适合远处抓拍、安静感、电影感
```

所以要记住：

```text
不是“某个对象只能用某个焦距”，
而是“不同焦距会讲不同的故事”。
```

当前阶段先背这个：

```text
28 看环境
50 看日常
100 看人
200 看细节
```

也可以说成：

```text
28mm 讲环境
50mm 讲日常
100mm 讲人物
200mm 讲细节
```

## 2.5 四焦段练习

找一个人、杯子、包、玩偶或任意主体，同一个主体拍四张：

```text
第 1 张：28mm
第 2 张：50mm
第 3 张：100mm
第 4 张：200mm
```

注意：

```text
1. 主体大小尽量保持差不多
2. 每次改变焦距后，自己前后移动
```

观察结果：

```text
28mm：背景很多，空间感强
50mm：自然、日常
100mm：背景开始柔和，主体更突出
200mm：背景变大，画面更紧凑
```

这个练习的目的：

```text
真正理解焦距，而不是只知道“拉近拉远”。
```

---

# 第三章 光圈和虚化

这一章学习一个很重要、也很容易让照片变好看的概念：光圈。

光圈决定两件事：

```text
1. 进光量：照片更亮还是更暗
2. 景深：背景更虚还是更清楚
```

新手先记一句话：

```text
光圈数字越小，光圈越大，背景越容易虚。
```

---

## 3.1 光圈是什么

光圈可以理解为镜头里的“窗户”。

窗户开得越大，进来的光越多；窗户开得越小，进来的光越少。

```text
大光圈                         小光圈
F2.8 / F4                       F8 / F11

   ◉                              ●
窗户大，进光多                  窗户小，进光少
背景更容易虚                    背景更容易清楚
适合人像、弱光、特写            适合风景、建筑、合影
```

光圈的难点在于：数字和大小是反着来的。

```text
F2.8  比  F8  的光圈更大
F8    比  F2.8 的光圈更小
```

可以这样记：

```text
F 后面的数字越小 = 光圈越大 = 背景越虚 = 画面越亮
F 后面的数字越大 = 光圈越小 = 背景越清楚 = 画面越暗
```

---

## 3.2 光圈数字怎么理解

常见光圈大概可以这样分：

```text
F1.4 / F1.8 / F2.0    超大光圈，虚化强，夜晚更有优势
F2.8 / F4             大光圈，人像、特写、弱光常用
F5.6                  中等光圈，日常、旅行很常用
F8 / F11              小光圈，风景、建筑、合影常用
F16                   很小光圈，特殊场景才常用
```

你的腾龙 28-200mm 镜头是 `F2.8-5.6`，意思是：

```text
28mm 端：最大光圈大约是 F2.8
200mm 端：最大光圈大约是 F5.6
```

也就是说，这支镜头的最大光圈会随着变焦变化。

```text
28mm       50mm       100mm       200mm
F2.8       约 F3.5     约 F4.5      F5.6
更亮       中间状态     中间状态      进光少一些
```

上面只是帮助理解的近似示意，实际数值以相机屏幕显示为准。

---

## 3.3 光圈和背景虚化的关系

背景虚化，就是主体清楚，背景柔和。

```text
主体清楚，背景虚：

相机  ->  人 | 清楚 |      背景 | 模糊模糊模糊 |

主体和背景都清楚：

相机  ->  人 | 清楚 |      背景 | 也清楚 |
```

光圈越大，景深越浅，背景越容易虚。

```text
F2.8：背景容易虚
F4：背景比较容易虚
F5.6：有一定虚化
F8：背景更清楚
F11：背景大多比较清楚
```

可以想象成“清楚的范围”厚不厚：

```text
大光圈 F2.8：清楚范围薄

相机 ->  [ 主体清楚 ]  背景很快变模糊

小光圈 F8：清楚范围厚

相机 ->  [ 主体清楚 ][ 后面也清楚 ][ 更后面还算清楚 ]
```

---

## 3.4 只靠光圈不一定能虚化

很多新手会以为：只要开大光圈，背景一定虚。

更准确地说，背景虚化由四个因素共同决定：

```text
1. 光圈越大，背景越虚
2. 焦距越长，背景越虚
3. 相机离主体越近，背景越虚
4. 主体离背景越远，背景越虚
```

这四个因素可以组合使用。

### 3.4.1 虚化不明显的情况

```text
相机        人        背景
  |---------|---------|

人离背景太近，即使用大光圈，背景也不一定很虚。
```

### 3.4.2 虚化更明显的情况

```text
相机      人                         背景
  |-------|--------------------------|

人离背景远，背景更容易虚。
```

再加上长焦，效果会更明显：

```text
100mm / 135mm / 200mm
主体更突出，背景更柔和，画面更干净。
```

---

## 3.5 你的 28-200mm 镜头怎么拍虚化

你的镜头虽然不是超大光圈定焦镜头，但它有一个很大的优势：焦段长。

所以你拍虚化时，不要只盯着 F 数字，还要利用长焦。

### 3.5.1 拍人像虚化

推荐设置和做法：

```text
焦距：85-135mm，或者 200mm 也可以
光圈：开到当前能开的最大光圈
距离：你离人近一点，人离背景远一点
对焦：对在人眼上
```

图像理解：

```text
相机          人                         背景
  |-----------|--------------------------|
  85-135mm       人清楚                    背景柔和
```

如果空间足够，可以试试 200mm：

```text
200mm + 人离背景远 = 主体突出，背景压缩，画面更有电影感
```

### 3.5.2 拍食物、杯子、花、物件

推荐做法：

```text
焦距：70-135mm
光圈：最大光圈
距离：相机靠近主体
背景：让主体后面有一些距离
```

画面会更像这样：

```text
相机      杯子                         背景
  |-------|----------------------------|
        杯子清楚                       背景虚
```

### 3.5.3 拍风景和建筑

风景不一定追求虚化，更常见的是前后都清楚。

推荐：

```text
焦距：28-50mm
光圈：F8 左右
ISO：尽量低
重点：地平线平，画面干净
```

风景的目标通常是：

```text
前景清楚 + 中景清楚 + 远处也清楚
```

---

## 3.6 不同场景的光圈选择

可以先按这个表来：

```text
人像、宠物、花、食物：最大光圈
日常记录：F4-F5.6
多人合照：F5.6-F8
风景、建筑：F8-F11
夜晚手持：最大光圈
```

更形象一点：

```text
想突出一个主体：用大光圈
想让整张都清楚：用小光圈
光线很暗：优先用大光圈
人很多排成几排：不要用太大光圈
```

多人合照为什么不建议光圈太大？

```text
F2.8：第一排清楚，后排可能虚
F5.6/F8：前后排更容易都清楚
```

---

## 3.7 光圈优先 A 档

后面真正操作相机时，我们会常用 `A 档`，也叫“光圈优先”。

意思是：

```text
你决定光圈，相机帮你决定快门。
```

适合新手的原因：

```text
你只要先想：我想背景虚，还是整张都清楚？
然后选择光圈，剩下交给相机处理。
```

简单决策：

```text
想背景虚：A 档 + 最大光圈
想整张清楚：A 档 + F8
```

但是要注意快门速度。

如果相机自动给出的快门太慢，照片可能会糊。

```text
拍静止的人：尽量不低于 1/125s
拍走动的人：尽量不低于 1/250s
```

---

## 3.8 这一章的小抄

```text
光圈数字越小，光圈越大
光圈越大，背景越容易虚，画面也更亮
光圈越小，背景越清楚，画面也更暗
```

拍虚化的口诀：

```text
大光圈 + 长焦 + 靠近主体 + 背景远
```

你的镜头拍虚化的推荐方式：

```text
人像：85-135mm / 200mm + 最大光圈 + 人离背景远
物件：70-135mm + 最大光圈 + 靠近主体
风景：28-50mm + F8 左右
```

---

## 3.9 本章练习

### 练习一：同一焦距，不同光圈

找一个杯子、玩偶、花或其他小物件。

保持焦距不变，比如 70mm 或 100mm，分别拍：

```text
第 1 张：最大光圈
第 2 张：F5.6
第 3 张：F8
```

观察：

```text
背景有没有越来越清楚？
主体有没有始终清楚？
画面亮度有没有变化？
```

### 练习二：同一光圈，不同距离

光圈保持最大，拍同一个物体。

```text
第 1 张：相机离主体远一点
第 2 张：相机离主体近一点
```

观察：

```text
离主体越近，背景是不是更虚？
```

### 练习三：主体离背景远一点

光圈保持最大，焦距用 100mm 左右。

```text
第 1 张：主体贴近背景
第 2 张：主体离背景远一点
```

观察：

```text
主体离背景越远，背景是不是更柔和？
```

# 第四章 快门和运动

这一章学习“快门”。

快门解决两个问题：

```text
1. 怎么避免照片拍糊
2. 怎么表现运动，是凝固住，还是拍出流动感
```

新手先记一句话：

```text
快门越快，越能拍清楚运动；快门越慢，越容易出现模糊和拖影。
```

---

## 4.1 快门是什么

快门可以理解为相机“睁眼”的时间。

相机睁眼越久，进来的光越多；相机睁眼越短，进来的光越少。

```text
快门快                         快门慢
1/1000s                         1/10s

睁眼时间短                     睁眼时间长
进光少                         进光多
动作更容易清楚                 动作更容易拖影
适合运动、人、动物             适合夜景、水流、创意模糊
```

快门速度通常写成这样：

```text
1/1000s
1/500s
1/250s
1/125s
1/60s
1/30s
1/10s
1s
```

注意：

```text
1/1000s 比 1/125s 更快
1/10s 比 1/125s 更慢
1s 是整整 1 秒，很慢
```

---

## 4.2 为什么照片会糊

照片糊，常见有两种原因。

### 4.2.1 手抖糊

手拿相机时，人不可能完全静止。

如果快门太慢，相机会把你手上的轻微晃动也记录下来。

```text
相机轻微晃动 + 快门太慢 = 整张照片都糊
```

画面感觉：

```text
建筑糊
人也糊
背景也糊
整张都不利落
```

### 4.2.2 主体运动糊

即使你拿相机很稳，拍摄对象自己在动，也可能糊。

```text
人走路 + 快门太慢 = 人糊，背景可能清楚
小孩跑动 + 快门太慢 = 小孩糊
车经过 + 快门太慢 = 车拖影
```

画面感觉：

```text
背景清楚，但人或车拖出影子
```

所以要分清：

```text
整张都糊：大概率是手抖
主体糊、背景清楚：大概率是主体在动
```

---

## 4.3 常见快门速度怎么选

新手可以先按这个表来：

```text
1/1000s  很快：运动、动物、跑步、车辆、抓拍瞬间
1/500s   快：小孩、宠物、街头快速动作
1/250s   常用：走动的人、日常抓拍
1/125s   人像安全线：站着的人、轻微动作
1/60s    勉强手持：静物、很安静的人
1/30s    容易手抖：建议稳定身体或有防抖
1/10s    很慢：容易拖影，适合创意或三脚架
1s       非常慢：夜景、车轨、水流，需要三脚架
```

更简单的记法：

```text
拍人不动：至少 1/125s
拍人走动：至少 1/250s
拍小孩宠物：1/500s 更稳
拍运动：1/1000s 左右
拍静物：1/60s 也可能够用
```

---

## 4.4 焦距越长，快门越要快

这是你用 28-200mm 镜头时特别重要的一点。

长焦会把远处拉近，但也会放大手抖。

```text
28mm：一点手抖不太明显
200mm：一点手抖会被放大很多
```

可以想象成：

```text
拿手电筒照近处：手晃一点，光斑移动不明显
拿手电筒照远处：手晃一点，远处光斑移动很明显
```

所以焦距越长，快门越要快。

新手安全参考：

```text
28mm：尽量不低于 1/60s
50mm：尽量不低于 1/100s
85mm：尽量不低于 1/160s
100mm：尽量不低于 1/200s
200mm：尽量不低于 1/400s
```

这不是死规定，而是安全线。

如果你拍的是会动的人，还要更快：

```text
85mm 拍站着的人：1/160s 或 1/250s
85mm 拍走动的人：1/250s 或更快
200mm 拍人像：1/400s 更稳
200mm 抓拍动作：1/500s 到 1/1000s 更稳
```

---

## 4.5 如何凝固动作

凝固动作，就是把运动中的瞬间拍清楚。

比如：

```text
跑步的人
跳起来的人
玩耍的小孩
奔跑的宠物
路上的车
风吹动的头发
```

要凝固动作，就用更快的快门。

```text
人走路：1/250s
小孩跑动：1/500s
宠物奔跑：1/1000s
体育运动：1/1000s 或更快
```

图像理解：

```text
快门慢：
人  ->  人影拖开，动作模糊

快门快：
人  ->  某一瞬间被定住，动作清楚
```

如果光线不够，相机可能会为了快门快而提高 ISO。

这时候要记住：

```text
有一点噪点，可以接受。
动作糊了，通常救不回来。
```

---

## 4.6 如何拍出运动感

不是所有照片都必须“完全清楚”。

有时候慢快门反而更有感觉，比如：

```text
水流变丝滑
车灯拉成长线
人群有流动感
地铁进站有速度感
```

### 4.6.1 慢快门拍水流

```text
快门：1/4s、1/2s、1s 或更慢
效果：水变柔和，像丝带
建议：使用三脚架或把相机放稳
```

### 4.6.2 慢快门拍车灯

```text
快门：1s 到 10s
效果：车灯变成光轨
建议：夜晚、三脚架、低 ISO
```

### 4.6.3 追随拍摄

追随拍摄是一个很有意思的技巧。

你跟着运动主体一起移动相机，让主体相对清楚，背景拉出速度线。

```text
主体：骑车的人 / 跑步的人 / 车
快门：1/30s 到 1/125s
动作：相机跟着主体平稳移动
效果：主体比较清楚，背景有横向拖影
```

图像理解：

```text
普通慢快门：主体糊，背景也可能乱
追随拍摄：主体相对清楚，背景有速度感
```

这个技巧需要练习，第一次失败很正常。

---

## 4.7 快门优先 S 档

后面真正操作相机时，我们会接触 `S 档`，也叫“快门优先”。

意思是：

```text
你决定快门，相机帮你决定光圈。
```

什么时候用 S 档？

```text
你最关心动作是否清楚时
你想拍运动感时
你想固定某个快门速度练习时
```

例子：

```text
拍小孩跑动：S 档 + 1/500s
拍宠物奔跑：S 档 + 1/1000s
拍走路的人：S 档 + 1/250s
拍追随：S 档 + 1/60s
拍水流：S 档 + 1/2s 或更慢
```

但 S 档也有一个问题：

```text
如果环境太暗，快门又设得太快，相机可能没有足够的光。
```

这时相机会尝试：

```text
开大光圈
提高 ISO
```

如果还是不够，照片就会偏暗。

---

## 4.8 这一章的小抄

```text
快门越快，动作越清楚，进光越少
快门越慢，拖影越明显，进光越多
```

常用安全值：

```text
静止人像：1/125s 起
走动的人：1/250s 起
小孩宠物：1/500s 起
运动抓拍：1/1000s 起
```

你的 28-200mm 镜头手持参考：

```text
28mm：不低于 1/60s
50mm：不低于 1/100s
85mm：不低于 1/160s
100mm：不低于 1/200s
200mm：不低于 1/400s
```

判断照片为什么糊：

```text
整张都糊：可能是手抖
主体糊、背景清楚：可能是主体动得太快
```

---

## 4.9 本章练习

### 练习一：同一个动作，不同快门

找一个人走路，或者让手在画面里挥动。

分别拍：

```text
第 1 张：1/60s
第 2 张：1/125s
第 3 张：1/250s
第 4 张：1/500s
```

观察：

```text
动作是不是越来越清楚？
画面是不是因为快门变快而更暗？
ISO 有没有自动升高？
```

### 练习二：长焦手持稳定性

把镜头转到 200mm，拍远处一个静止物体。

分别拍：

```text
第 1 张：1/60s
第 2 张：1/125s
第 3 张：1/250s
第 4 张：1/500s
```

观察：

```text
哪一张开始明显变清楚？
200mm 是不是比 28mm 更容易手抖？
```

### 练习三：慢快门运动感

找一辆经过的车，或者让人从画面前走过。

试试：

```text
1/30s
1/15s
1/8s
```

观察：

```text
运动主体有没有拖影？
背景是否还清楚？
你喜不喜欢这种运动感？
```

# 第五章 ISO 和噪点

这一章学习 ISO。

ISO 很容易被新手误解。很多人一听到 ISO 高就害怕，觉得照片会脏、会有噪点。

但更准确地说：

```text
ISO 是在光线不够时，帮你把照片变亮的工具。
```

新手先记一句话：

```text
宁愿 ISO 高一点，也不要为了低 ISO 把照片拍糊。
```

---

## 5.1 ISO 是什么

ISO 可以理解为相机的“亮度增益”。

如果光圈和快门已经确定，但照片还是太暗，相机可以通过提高 ISO 让画面变亮。

```text
ISO 低                         ISO 高
ISO 100                         ISO 3200 / 6400

画面更干净                     画面更亮
噪点更少                       噪点更多
适合白天、光线好               适合室内、夜晚、阴天
```

可以把 ISO 想象成音响音量：

```text
音量开小：声音干净，但可能听不清
音量开大：声音更响，但底噪也更明显
```

ISO 也是类似：

```text
ISO 低：画面干净，但需要足够光线
ISO 高：画面变亮，但噪点更明显
```

---

## 5.2 ISO 为什么会产生噪点

噪点就是照片里那些细小的颗粒、杂色或不干净的纹理。

尤其在暗部更容易看到。

```text
ISO 100：画面细腻
ISO 3200：暗部开始有颗粒
ISO 6400：颗粒更明显
ISO 12800：噪点比较明显，但有时仍然可用
```

噪点大概像这样：

```text
干净画面：
天空：平滑、细腻、颜色均匀

高 ISO 画面：
天空：有细小颗粒、颜色不那么纯净
```

但要注意：

```text
噪点不是照片失败。
拍糊，往往比有噪点更严重。
```

因为噪点后期可以改善一点，拍糊通常很难救回来。

---

## 5.3 ISO、光圈、快门怎么互相配合

摄影的曝光三角是一起工作的。

```text
光圈：镜头窗户开多大
快门：相机睁眼多久
ISO：把收到的光放大多少
```

当光线不够时，你通常有三个选择：

```text
1. 开大光圈：让更多光进来
2. 放慢快门：让相机接光更久
3. 提高 ISO：把画面增亮
```

但是每个选择都有代价：

```text
开大光圈：背景更虚，景深更浅
放慢快门：更容易手抖或主体糊
提高 ISO：噪点更多
```

所以实际拍摄时，要看你最不能接受什么。

### 5.3.1 拍人时

拍人最怕糊，尤其是眼睛糊。

所以顺序通常是：

```text
先开大光圈
再保证快门够快
最后让 ISO 自动升高
```

例如室内拍人：

```text
光圈：最大光圈
快门：至少 1/125s 或 1/250s
ISO：让相机自动提高
```

这时 ISO 到 3200、6400，也比人脸糊掉更好。

### 5.3.2 拍风景时

风景通常不怕主体乱动，更在意画面干净和前后清楚。

所以可以：

```text
光圈：F8 左右
ISO：尽量低
快门：慢一点也可以，但最好把相机拿稳或用三脚架
```

---

## 5.4 常见 ISO 数值怎么选

新手可以先按这个表理解：

```text
ISO 100-200：晴天、光线很好、画质最干净
ISO 400：阴天、树荫、室内靠窗
ISO 800：普通室内、傍晚
ISO 1600：较暗室内、夜晚街景
ISO 3200：暗光室内、夜晚抓拍
ISO 6400：更暗的环境，保住快门优先
ISO 12800：应急可用，噪点明显
```

更口语一点：

```text
白天户外：ISO 100-400
阴天或室内：ISO 800-3200
夜晚手持：ISO 3200-12800 都可能用到
```

不要把这些数字当成绝对规定。

它们只是帮你建立感觉：

```text
光线越暗，ISO 往往越高。
```

---

## 5.5 自动 ISO 怎么理解

新手阶段，推荐使用自动 ISO。

自动 ISO 的意思是：

```text
相机会根据现场光线，自动帮你选择 ISO。
```

你可以把它理解为一个会帮你补亮的助手。

```text
光线好：相机自动用低 ISO
光线差：相机自动提高 ISO
```

在 A 档，也就是光圈优先时，常见逻辑是：

```text
你决定光圈
相机决定快门
如果光线不够，相机提高 ISO
```

但要注意：

```text
自动 ISO 不等于万能。
```

如果最低快门设置太慢，相机可能为了降低 ISO 而让快门变慢，结果照片糊掉。

所以后面操作相机时，我们会学习：

```text
Auto ISO + 最低快门速度
```

比如拍人时，可以让相机尽量不要低于：

```text
1/125s 或 1/250s
```

---

## 5.6 新手最容易犯的 ISO 错误

### 5.6.1 错误一：为了 ISO 低，快门太慢

比如室内拍人：

```text
ISO 100
快门 1/20s
```

画质看起来也许干净，但人很容易糊。

更好的选择：

```text
ISO 1600 或 3200
快门 1/125s 或 1/250s
```

这样虽然有一点噪点，但人是清楚的。

### 5.6.2 错误二：白天还固定高 ISO

比如大白天户外还固定 ISO 6400。

这会让画面没有必要地变脏，也可能导致照片过曝。

所以：

```text
白天光线好：ISO 100-400
光线变暗：再提高 ISO
```

如果你使用自动 ISO，相机会帮你避免很多这类问题。

### 5.6.3 错误三：看到噪点就觉得照片废了

有些好照片本来就有噪点，尤其是夜晚、街头、纪实照片。

更重要的是：

```text
主体清楚
表情好
光线好
构图舒服
```

这些通常比“百分百放大时有没有噪点”更重要。

---

## 5.7 你的相机和镜头怎么用 ISO

你这套设备是全画幅机身加 28-200mm 镜头，暗光能力比手机和小底相机会好不少。

可以比较放心地使用较高 ISO。

### 5.7.1 日常推荐思路

如果你用 A 档拍摄：

```text
光圈：根据虚化需要选择
ISO：自动 ISO
快门：注意不要太慢
```

拍人时：

```text
光圈：最大光圈
快门：至少 1/125s，走动的人 1/250s
ISO：自动提高，必要时 3200、6400 也可以接受
```

拍风景时：

```text
光圈：F8 左右
ISO：100-400
快门：如果太慢，就拿稳或用三脚架
```

拍夜景手持时：

```text
光圈：最大光圈
快门：不要低到手抖
ISO：让它升高
```

### 5.7.2 和 28-200mm 镜头的关系

你的镜头在 200mm 端最大光圈是 F5.6，比 28mm 端的 F2.8 进光少。

也就是说：

```text
同样的夜晚环境下，200mm 往往需要更高 ISO。
```

因为长焦还需要更快的快门避免手抖：

```text
200mm 手持建议约 1/400s 起
```

所以 200mm 在暗光下拍摄时，ISO 可能会升得比较高。

这很正常。

---

## 5.8 这一章的小抄

```text
ISO 越低，画面越干净，但需要更多光
ISO 越高，画面越亮，但噪点更多
```

最重要的判断：

```text
照片有噪点，很多时候还能接受
照片拍糊，通常更难挽救
```

常用 ISO：

```text
白天户外：ISO 100-400
阴天/室内：ISO 800-3200
夜晚手持：ISO 3200-12800
```

拍人优先级：

```text
人清楚 > 噪点少
```

实用口诀：

```text
先开光圈，再保快门，最后交给 ISO。
```

找一个室内场景，固定光圈和快门，分别拍：

```

观察：

```

找一个人坐着或轻微移动。

第 1 张：ISO 100，快门较慢

```

哪张人更清楚？

清楚通常比干净更重要。

```

观察相机屏幕上的 ISO：

```text
光线越暗，ISO 是不是越高？
相机有没有为了保持亮度自动调整 ISO？
```

# 第六章 对焦和清晰

这一章学习“对焦”。

前面我们学了光圈、快门、ISO，它们决定照片的亮度、虚化、运动清晰度。对焦解决的是另一个问题：

```text
照片里哪里应该最清楚？
```

新手先记一句话：

```text
拍人优先对眼睛，拍物优先对主体最重要的位置。
```

---

## 6.1 对焦是什么

对焦，就是告诉相机：这张照片里哪一块必须清楚。

```text
相机看到整个画面
你告诉它：这里最重要
相机就尽量让这里最清楚
```

可以这样理解：

```text
对焦点 = 清晰优先级最高的位置
```

比如拍人：

```text
对到眼睛：眼睛清楚，照片有神
对到衣服：衣服清楚，脸可能不够清楚
对到背景：背景清楚，人可能糊掉
```

所以拍照时，不只是“按快门”，还要知道：

```text
相机现在到底在对哪里？
```

---

## 6.2 清晰和不糊不是一回事

新手容易把“没对上焦”和“快门太慢拍糊”混在一起。

它们看起来都不清楚，但原因不同。

### 6.2.1 没对上焦

没对上焦，就是相机把清楚的位置放错了。

```text
人脸不清楚，背景清楚
眼睛不清楚，耳朵或衣服清楚
主体不清楚，旁边的东西清楚
```

这叫“焦点跑了”。

图像理解：

```text
应该清楚：人眼
实际清楚：背景树叶
结果：人看起来不精神
```

### 6.2.2 快门太慢拍糊

快门太慢，是因为相机或主体移动了。

```text
整张都糊：可能是手抖
主体拖影：可能是主体在动
```

图像理解：

```text
对焦位置可能没错
但快门太慢，动作被拖成影子
```

简单区分：

```text
某个错误位置很清楚：可能是没对上焦
整张发虚或有拖影：可能是快门太慢
```

---

## 6.3 对焦点应该放在哪里

不同题材，对焦位置不同。

### 6.3.1 拍人

拍人最重要的是眼睛。

```text
眼睛清楚 > 脸清楚 > 衣服清楚 > 背景清楚
```

如果是正脸：

```text
优先对离相机更近的那只眼睛
```

如果人侧脸：

```text
对靠近镜头的眼睛
```

为什么眼睛这么重要？

```text
人看照片时，第一眼会看眼睛。
眼睛清楚，照片就有精神。
眼睛糊了，其他地方再清楚也会觉得可惜。
```

### 6.3.2 拍动物

拍动物也优先对眼睛。

```text
眼睛清楚，动物有神
鼻子清楚但眼睛糊，照片会弱很多
```

### 6.3.3 拍食物和物件

拍物件时，对焦点放在“最想让人看的地方”。

```text
拍咖啡：对杯沿、拉花或杯身标志
拍蛋糕：对最漂亮的装饰或切面
拍花：对花蕊或最靠前的一片花瓣
拍手表：对表盘或品牌标志
```

### 6.3.4 拍风景

风景通常希望大范围都清楚。

常见做法：

```text
光圈用 F8 左右
对焦在画面中前方或主体建筑上
避免只对很近的前景，导致远处不够清楚
```

新手可以先简单记：

```text
风景有主体，就对主体
没有明确主体，就对画面中间偏远一点的位置
```

---

## 6.4 AF-S、AF-C、MF 怎么理解

相机常见对焦模式有三类。

```text
AF-S：单次自动对焦
AF-C：连续自动对焦
MF：手动对焦
```

### 6.4.1 AF-S 单次自动对焦

AF-S 适合静止主体。

```text
半按快门对焦
对上后锁定
主体不动时很适合
```

适合：

```text
静物
风景
建筑
摆拍的人像
```

### 6.4.2 AF-C 连续自动对焦

AF-C 适合会动的主体。

```text
半按快门或按对焦按钮时
相机会持续追踪、持续调整焦点
```

适合：

```text
走动的人
小孩
宠物
街拍
抓拍
运动
```

拍人时，新手可以优先用 AF-C。

因为人就算站着，也会轻微前后晃动。

### 6.4.3 MF 手动对焦

MF 是自己转动对焦环，让画面清楚。

适合：

```text
微距
夜景
特殊创作
自动对焦很难判断的场景
```

新手日常不需要优先用 MF。

```text
日常、人像、旅行：自动对焦更省心
```

---

## 6.5 对焦区域怎么选

对焦区域可以理解为：你允许相机在哪个范围内找焦点。

常见思路：

```text
广域：让相机在大范围里找主体
区域：让相机在某一块区域里找主体
点：你精确指定一个小点
跟踪：锁定主体后持续跟着它
```

### 6.5.1 广域

广域适合新手日常使用。

```text
相机会在大范围里识别主体
配合人脸/人眼识别很好用
```

适合：

```text
旅行
人像
日常抓拍
街拍
```

### 6.5.2 点对焦

点对焦更精确，但需要你自己放准位置。

```text
优点：可控
缺点：主体一动，点可能就不在主体上了
```

适合：

```text
静物
风景中明确的小主体
隔着前景拍某个东西
```

### 6.5.3 跟踪对焦

跟踪对焦适合主体会动的情况。

```text
先选中主体
相机持续跟着它
主体移动时，相机也跟着调整焦点
```

适合：

```text
走动的人
小孩
宠物
街头抓拍
```

---

## 6.6 人眼对焦为什么重要

索尼相机的人眼识别很强，这是拍人的大优势。

人眼对焦的作用是：

```text
相机自动识别人的眼睛
并把焦点优先放在眼睛上
```

这能大大减少新手拍人时的失败率。

拍人时，如果相机识别到眼睛，你通常会看到屏幕上有小框框锁在眼睛附近。

```text
小框在眼睛上：很安心
小框在脸上：也还不错
小框跑到背景：要小心
```

拍人像时的优先级：

```text
眼睛清楚：最好
脸清楚：可接受
衣服清楚：不理想
背景清楚：失败概率高
```

---

## 6.7 常见对焦失败原因

### 6.7.1 对到背景了

常见于主体太小、背景纹理太明显。

```text
人站得远
背景树叶或建筑线条很多
相机可能误以为背景更好对焦
```

解决：

```text
让主体大一点
靠近一点拍
使用人眼识别或跟踪对焦
必要时用点对焦放在人脸上
```

### 6.7.2 光线太暗

暗光下，相机更难判断焦点。

```text
室内昏暗
夜晚街头
逆光人脸太暗
```

解决：

```text
找更亮的位置
让人脸朝向光
提高 ISO 保住快门
必要时半按快门多对一次
```

### 6.7.3 景深太浅

大光圈、近距离、长焦时，清楚范围会很薄。

```text
眼睛清楚，耳朵虚：正常
睫毛清楚，眼球不够清楚：景深太浅或焦点略偏
```

解决：

```text
对准眼睛
人不要晃动太大
必要时光圈收小一点，比如 F4 或 F5.6
```

### 6.7.4 主体移动太快

对焦跟上了，但快门不够快，也会糊。

解决：

```text
使用 AF-C
提高快门速度
连拍多拍几张
```

---

## 6.8 你的相机拍人推荐对焦思路

你是索尼机身，拍人可以先用一个很稳的思路：

```text
对焦模式：AF-C
识别目标：人
对焦区域：广域或跟踪
重点：确认小框落在人脸或眼睛上
```

拍单人半身像：

```text
焦距：85-135mm
光圈：最大光圈或 F4
快门：至少 1/125s，走动就 1/250s
对焦：人眼
```

拍全身人像：

```text
焦距：50-100mm
距离：根据构图后退
对焦：人脸/人眼
注意：背景干净，人不要贴背景太近
```

拍小孩或宠物：

```text
对焦模式：AF-C
快门：1/500s 起
连拍：可以开启
ISO：让它自动升高
```

如果你发现照片总是人不清楚，优先检查这三件事：

```text
1. 焦点是不是在眼睛或脸上
2. 快门是不是太慢
3. 人是不是离背景太近，导致主体不突出
```

---

## 6.9 这一章的小抄

```text
对焦 = 告诉相机哪里最重要、哪里要最清楚
```

拍摄题材和对焦位置：

```text
拍人：对眼睛
拍动物：对眼睛
拍食物：对最想展示的位置
拍商品：对标志、纹理或关键细节
拍风景：对主体或画面中前方
```

对焦模式：

```text
AF-S：静止主体
AF-C：移动主体，日常拍人也推荐
MF：手动对焦，特殊场景使用
```

拍人推荐：

```text
AF-C + 人眼识别 + 广域/跟踪
```

判断问题：

```text
背景清楚人不清楚：可能对错地方
整张都糊：可能手抖或快门太慢
人有拖影：可能主体动了，快门不够快
```

## 6.10 本章练习

### 练习一：眼睛对焦

找一个人或玩偶，拍半身照片。

分别尝试：

```text
第 1 张：对眼睛
第 2 张：对衣服
第 3 张：对背景
```

观察：

```text
哪一张看起来最舒服？
眼睛清楚时，照片是不是更有精神？
```

### 练习二：AF-S 和 AF-C 对比

找一个人从远处慢慢走向你。

分别尝试：

```text
AF-S 拍几张
AF-C 拍几张
```

观察：

```text
人移动时，哪种模式更容易保持清楚？
```

### 练习三：点对焦和广域对焦

拍桌上的一个小物件。

分别尝试：

```text
广域对焦
点对焦
```

观察：

```text
相机有没有选错主体？
点对焦是不是更可控？
广域是不是更方便？
```

# 第七章 构图和画面取舍

这一章学习“构图”。

前面几章解决的是：照片亮不亮、清不清楚、虚不虚、糊不糊。

构图解决的是：

```text
这张照片到底让人看什么？
画面为什么舒服，或者为什么乱？
```

新手先记一句话：

```text
构图不是把东西拍进去，而是决定哪些东西不要拍进去。
```

---

## 7.1 构图是什么

构图就是安排画面里的元素。

你可以把照片想象成一个舞台：

```text
谁是主角？
谁是配角？
背景干不干净？
观众第一眼会看哪里？
```

一张照片看起来舒服，通常不是因为画面里东西很多，而是因为：

```text
主体明确
背景干净
位置舒服
边缘不乱
光线好看
```

构图的第一步不是找技巧，而是问自己：

```text
我这张照片想拍什么？
```

如果你自己都不知道主体是什么，观众也很难看懂。

---

## 7.2 主体：照片到底想让人看什么

主体就是照片里的“主角”。

主体可以是：

```text
一个人
一只猫
一杯咖啡
一朵花
一栋建筑
一道光
一个动作
一种氛围
```

新手最常见的问题是：画面里什么都有，但没有主角。

```text
人、树、车、垃圾桶、招牌、路人、天空全都进来了
结果：不知道该看哪里
```

拍之前先问一句：

```text
这张照片，我最想让人看什么？
```

然后让主体更明显。

常见方法：

```text
靠近主体
用长焦压缩背景
用大光圈虚化背景
换角度避开杂物
等路人走开再拍
让主体出现在更舒服的位置
```

图像理解：

```text
主体不明确：
┌────────────────────┐
│ 人  车  树  招牌  杂物 │
│ 桌子 路人 天空 电线    │
└────────────────────┘

主体明确：
┌────────────────────┐
│        背景干净       │
│          人           │
│        视线集中       │
└────────────────────┘
```

---

## 7.3 背景：好照片从干净背景开始

很多照片不好看，不是主体不好，而是背景太乱。

拍照前，除了看主体，也要看主体后面有什么。

检查背景时，重点看：

```text
有没有垃圾桶
有没有电线杆从头顶长出来
有没有亮得刺眼的招牌
有没有杂乱的人群
有没有颜色特别抢眼的东西
有没有横线穿过脖子或头部
```

新手可以练一个动作：

```text
拍之前，眼睛绕着画面边缘看一圈。
```

尤其注意四个角：

```text
左上角
右上角
左下角
右下角
```

很多杂物都藏在画面边缘。

如果背景乱，可以这样处理：

```text
换一个角度
往左或往右走一步
蹲低一点或站高一点
让主体离背景远一点
用更长焦段拍
用更大光圈拍
靠近主体，只拍局部
```

简单记：

```text
背景越干净，主体越突出。
```

---

## 7.4 三分法：让画面更自然

三分法是最常用、也最适合新手的构图方法。

把画面横竖各分成三等份：

```text
┌──────┬──────┬──────┐
│      │      │      │
├──────┼──────┼──────┤
│      │      │      │
├──────┼──────┼──────┤
│      │      │      │
└──────┴──────┴──────┘
```

四个交叉点，是比较舒服的位置：

```text
┌──────┬──────┬──────┐
│      │      │      │
├──────●──────●──────┤
│      │      │      │
├──────●──────●──────┤
│      │      │      │
└──────┴──────┴──────┘
```

拍人时，可以把眼睛放在上方三分线附近：

```text
┌──────────────────┐
│      眼睛在这里     │
│        人脸         │
│        身体         │
└──────────────────┘
```

拍风景时，可以把地平线放在上三分之一或下三分之一：

```text
天空好看：地平线放低，多留天空
地面好看：地平线放高，多留地面
```

但三分法不是法律。

居中也可以很好看，尤其适合：

```text
对称建筑
正面人像
仪式感强的画面
极简构图
```

新手阶段可以先这样判断：

```text
不知道怎么放：先试三分法
画面很对称：可以大胆居中
```

---

## 7.5 留白和呼吸感

留白就是给主体周围留出空间。

留白不一定是白色，可以是天空、墙面、水面、地面、虚化背景。

```text
没有留白：
主体被画面挤住，看起来压迫

有留白：
主体有空间，画面更舒服
```

拍人时，尤其要注意视线方向。

如果人看向右边，可以在右边多留一点空间：

```text
┌────────────────────┐
│    人  →            │
│          留出视线空间 │
└────────────────────┘
```

如果人往左走，也可以在左边留空间：

```text
┌────────────────────┐
│ 留出前进空间   ← 人  │
└────────────────────┘
```

这叫“视线空间”或“运动空间”。

简单记：

```text
人往哪里看，就给哪里留点空间。
人往哪里走，就给哪里留点空间。
```

---

## 7.6 前景、中景、背景

照片如果只有一个平面，容易显得单薄。

可以把画面分成三层：

```text
前景：离相机最近的东西
中景：主体所在的位置
背景：主体后面的环境
```

图像理解：

```text
相机  ->  前景  ->  主体  ->  背景
```

比如拍人像：

```text
前景：一片模糊的树叶或窗框
中景：人物
背景：远处的灯、墙、街道
```

这样画面会更有层次。

但新手要注意：

```text
前景是加分项，不是必须项。
前景太乱，反而会挡住主体。
```

可以先练简单版本：

```text
主体离背景远一点
用长焦拍
背景自然虚化
```

这就是最实用的层次感。

---

## 7.7 横拍、竖拍和拍摄高度

同一个场景，横拍和竖拍感觉不同。

### 7.7.1 横拍

横拍适合交代环境。

```text
风景
街道
多人合照
人和环境的关系
宽阔空间
```

画面感觉：

```text
┌──────────────────────┐
│      环境更完整        │
│   人和周围关系更明显    │
└──────────────────────┘
```

### 7.7.2 竖拍

竖拍适合突出人或高的物体。

```text
人像
全身照
建筑
树
手机分享
```

画面感觉：

```text
┌──────────┐
│   人脸    │
│   身体    │
│   全身    │
└──────────┘
```

拍人时，新手可以多试竖拍，因为人的身体本来就是竖向的。

### 7.7.3 拍摄高度

相机高度会影响照片感觉。

```text
眼平拍：自然、舒服
低机位：人物更高、更有气势
高机位：人物更小、更可爱或更柔和
```

拍人时，常用参考：

```text
拍半身：镜头大约在胸口到眼睛高度
拍全身：镜头大约在腰部到胸口高度
拍小孩：蹲下来，接近小孩眼睛高度
```

很多新手拍小孩不好看，是因为一直站着往下拍。

```text
你蹲下来，画面会立刻亲近很多。
```

---

## 7.8 常见构图错误

### 7.8.1 主体太小

很多新手拍照会离主体太远。

```text
人只有画面里小小一块
周围全是无关环境
```

解决：

```text
靠近一点
用长焦一点
裁掉不重要的部分
```

### 7.8.2 背景太乱

主体后面杂物太多，会抢注意力。

解决：

```text
换角度
等一等
让主体离背景远一点
用大光圈或长焦
```

### 7.8.3 头顶空间太多

拍人时，头顶留太多空间，人物会显得矮小。

```text
错误感觉：上面一大片空，人物挤在下面
```

解决：

```text
稍微向下调整构图
让眼睛接近上三分线
```

### 7.8.4 切到关节

拍人时，不建议正好从关节处切掉。

尽量避免切在：

```text
脖子
手腕
手肘
膝盖
脚踝
```

更自然的裁切位置：

```text
胸口附近
大腿中部
小腿中部
腰部以上的半身
```

### 7.8.5 画面歪了

风景、建筑、地平线尤其明显。

解决：

```text
拍摄时打开网格线
后期稍微旋转校正
```

---

## 7.9 这一章的小抄

构图第一问：

```text
这张照片想让人看什么？
```

新手最有用的五件事：

```text
主体明确
背景干净
边缘检查
适当留白
多走一步换角度
```

三分法：

```text
人眼放在上三分线附近
风景地平线放在上三分或下三分
不知道怎么放，先试三分法
对称画面，可以居中
```

拍人注意：

```text
眼睛清楚
头顶别留太多
不要从关节处切掉
人往哪里看，就给哪里留空间
```

---

## 7.10 本章练习

### 练习一：主体变明确

找一个杯子、包、花或人，拍三张：

```text
第 1 张：站远一点，把很多环境拍进去
第 2 张：靠近一点，只保留必要背景
第 3 张：再靠近一点，突出主体细节
```

观察：

```text
哪一张主体最明确？
哪一张背景最干净？
你最喜欢哪一张？
```

### 练习二：三分法和居中

拍同一个主体，分别拍：

```text
第 1 张：主体居中
第 2 张：主体放左三分之一
第 3 张：主体放右三分之一
```

观察：

```text
哪张更稳定？
哪张更自然？
哪张更有故事感？
```

### 练习三：检查背景

拍人像或物件时，先随手拍一张。

然后重新观察背景，处理掉干扰：

```text
换角度
移开杂物
等路人走开
让主体离背景远一点
```

再拍第二张。

观察：

```text
第二张是不是主体更突出？
画面是不是更干净？
```

### 练习四：横拍和竖拍

同一个人或同一个场景，分别拍：

```text
横拍一张
竖拍一张
```

观察：

```text
横拍是不是更有环境？
竖拍是不是更突出主体？
哪张更适合发手机朋友圈？
```

# 第八章 光线和拍摄时间

这一章学习“光线”。

摄影这件事，说到底是在记录光。参数可以让照片正确曝光，构图可以让照片有重点，但光线决定照片的质感和情绪。

新手先记一句话：

```text
好看的照片，往往先赢在光线，而不是赢在参数。
```

---

## 8.1 光线为什么重要

同一个人、同一个地点、同一台相机，不同光线下拍出来会完全不一样。

```text
好光线：脸更立体，颜色更舒服，背景更有层次
差光线：脸上阴影乱，眼睛没神，画面灰或刺眼
```

可以这样理解：

```text
相机参数：决定照片能不能拍清楚
构图：决定照片看什么
光线：决定照片有没有质感
```

拍照前，新手可以先问自己：

```text
光从哪里来？
光照在主体哪里？
主体脸上有没有难看的阴影？
背景是不是比主体还亮？
```

只要你开始看光，照片会明显进步。

---

## 8.2 光的方向：顺光、侧光、逆光

光的方向，会直接影响主体的立体感。

### 8.2.1 顺光

顺光就是光从你身后照向主体。

```text
太阳/灯光  ->  主体
相机也在光的方向附近
```

特点：

```text
脸比较亮
细节清楚
阴影少
容易拍得平
```

适合：

```text
旅行记录
合影
需要清楚展示主体的照片
```

缺点：

```text
立体感可能弱
正午太阳顺光时，人容易眯眼
```

### 8.2.2 侧光

侧光就是光从主体侧面照过来。

```text
光  ->  主体侧面
相机在主体前方
```

特点：

```text
一边亮，一边暗
脸和物体更有立体感
纹理更明显
```

适合：

```text
人像
静物
食物
建筑
有质感的画面
```

侧光通常很容易拍出高级感。

### 8.2.3 逆光

逆光就是光从主体后面照过来。

```text
光  ->  主体背后  ->  相机
```

特点：

```text
轮廓好看
头发边缘会发亮
背景容易很亮
人脸可能变黑
```

适合：

```text
傍晚人像
氛围感照片
剪影
有光边的画面
```

逆光很好看，但需要注意曝光。

```text
如果人脸太暗，可以加曝光补偿，或者让人稍微转向有光的一侧。
```

---

## 8.3 光的软硬：柔光和硬光

除了方向，光还有“软”和“硬”。

### 8.3.1 硬光

硬光就是很直接、很强的光。

比如：

```text
正午太阳
裸露灯泡
强烈手电
舞台强光
```

特点：

```text
阴影边缘很清楚
明暗反差大
脸上容易有难看的阴影
画面更强烈、更硬朗
```

硬光不是不能用，但新手不容易控制。

### 8.3.2 柔光

柔光就是被扩散过、比较温和的光。

比如：

```text
阴天
窗帘后的窗光
清晨和傍晚的阳光
树荫下的散射光
白墙反射的光
```

特点：

```text
阴影柔和
皮肤更好看
颜色更舒服
新手更容易拍成功
```

拍人时，新手优先找柔光。

```text
阴天不是坏天气，阴天其实很适合拍人。
```

---

## 8.4 一天里什么时候更适合拍照

一天里光线变化很大。

### 8.4.1 清晨和傍晚

清晨、傍晚的光更低、更暖、更柔和。

```text
时间：日出后、日落前
特点：光线斜，阴影长，颜色暖
适合：人像、街拍、风景、旅行照
```

这段时间常被叫做“黄金时刻”。

```text
金色阳光 + 柔和阴影 = 很容易出片
```

### 8.4.2 正午

正午太阳高，光线硬，阴影重。

```text
头顶亮
眼窝暗
鼻子下面有重阴影
人容易眯眼
```

不太适合新手直接拍人。

如果正午必须拍，可以这样做：

```text
找阴影处
找树荫
进室内靠窗
让人背对太阳，用逆光拍
避免让太阳直射脸
```

### 8.4.3 蓝调时刻和夜晚

日落后天还没完全黑时，天空会有蓝色。

```text
适合：城市灯光、夜景、人像氛围
注意：光线变暗，快门和 ISO 要注意
```

夜晚拍摄时：

```text
找有光的地方
让脸靠近灯光
不要站在完全黑的地方
```

---

## 8.5 室内窗边光怎么用

窗边光是新手最容易获得的好光。

窗户就像一个很大的柔光箱。

```text
窗户  ->  柔和光线  ->  人/物体
```

拍人时可以这样站：

```text
窗户在人物侧前方
人脸转向窗户一点点
相机在人物正前方或斜前方
```

图像理解：

```text
窗户光
  |
  v
[窗]        人
            |\
            | \  相机
```

效果：

```text
一边脸亮，一边脸稍暗
脸有立体感
皮肤更柔和
眼睛有光
```

拍物件、食物也一样：

```text
把食物放在窗边
让光从侧面照过来
背景保持干净
用 50-100mm 拍
```

注意：

```text
不要让窗户直接出现在画面里太亮的位置，除非你就是想拍逆光氛围。
```

---

## 8.6 逆光人像怎么拍

逆光人像很有氛围，但新手容易把人脸拍黑。

常见问题：

```text
背景很好看，人脸黑成一片
太阳太亮，画面发灰
对焦不稳定
```

可以这样做：

```text
让太阳不要直接进镜头
用树、建筑、人的头发挡住一部分太阳
让人脸稍微转向有光的一侧
适当加曝光补偿，比如 +0.3 到 +1.0
对焦在人眼上
```

图像理解：

```text
太阳在人物后方
人物脸稍微转向侧面亮处
相机对眼睛
曝光稍微加一点
```

如果想拍剪影，就反过来：

```text
让背景曝光正常
人脸不用补亮
主体变成黑色轮廓
```

剪影适合：

```text
日落
桥上
海边
窗边
动作轮廓清楚的人
```

---

## 8.7 常见光线错误

### 8.7.1 人站在顶光下面

比如正午太阳下，或者头顶灯正下方。

问题：

```text
眼窝黑
鼻子下面阴影重
脸看起来疲惫
```

解决：

```text
让人移动到阴影里
找窗边侧光
让人脸转向更柔和的光
```

### 8.7.2 背景比人亮太多

比如人站在室内，背后是很亮的窗户。

问题：

```text
相机为了保住窗外亮部，人脸会变黑
```

解决：

```text
让人转向窗户
换角度，不把亮窗户放在正后方
加曝光补偿
靠近人拍，减少亮背景比例
```

### 8.7.3 混合光太乱

比如室内有黄灯、窗外蓝光、屏幕绿光混在一起。

问题：

```text
脸色奇怪
一边黄一边蓝
后期也不好调
```

解决：

```text
关掉一部分灯
靠近主要光源
尽量让脸只被一种主要光照亮
```

### 8.7.4 光很好，但主体没有站到光里

有时候场景里明明有好光，但主体站在暗处。

解决：

```text
让人往光里走一步
让脸转向光
等待光照到主体
```

---

## 8.8 这一章的小抄

拍照前先看光：

```text
光从哪里来？
照在主体哪里？
脸上阴影好不好看？
背景是不是比主体还亮？
```

光线方向：

```text
顺光：清楚，但可能平
侧光：立体，适合人像和静物
逆光：有氛围，但人脸容易暗
```

光线软硬：

```text
硬光：反差强，阴影重，新手难控制
柔光：阴影柔，皮肤好看，新手更容易成功
```

好拍时间：

```text
清晨、傍晚：最容易出片
阴天：适合拍人
正午：尽量找阴影
夜晚：找有光的地方拍
```

实用口诀：

```text
拍人先找柔光，拍物先找侧光，逆光记得看人脸。
```

## 8.9 本章练习

### 练习一：同一个人，不同光线方向

找一个人站在窗边或户外。

分别拍：

```text
第 1 张：顺光
第 2 张：侧光
第 3 张：逆光
```

观察：

```text
哪张脸最清楚？
哪张最立体？
哪张最有氛围？
```

### 练习二：硬光和柔光对比

分别在两个地方拍同一个主体：

```text
强烈直射光下
阴影里或窗帘后的柔光下
```

观察：

```text
阴影边缘有什么不同？
皮肤或物体质感有什么不同？
哪张更舒服？
```

### 练习三：窗边光

把一个杯子、花、书或人放在窗边。

尝试：

```text

窗户在背后
```

观察：

```text
哪种光最有立体感？
逆光时主体是不是容易变暗？
```

### 练习四：正午找阴影

中午户外拍人，分别拍：

```text

```

观察：

```text
眼窝阴影有没有变轻？
人是不是不那么容易眯眼？
肤色是不是更舒服？
```

# 第九章 色彩和白平衡

这一章学习“色彩”和“白平衡”。

前面我们学了光线，但同样的光线下，照片颜色也可能完全不同。

```text
有的照片偏黄
有的照片偏蓝
有的照片脸色发绿
有的照片颜色很舒服
```

新手先记一句话：

```text
白平衡控制照片冷暖，色彩决定照片情绪。
```

---

## 9.1 色彩为什么重要

色彩会影响照片给人的第一感觉。

```text
暖色：温柔、日落、亲近、生活感
冷色：安静、清爽、夜晚、距离感
高饱和：鲜艳、活泼、强烈
低饱和：克制、耐看、安静
```

同一张照片，颜色不同，情绪也不同：

```text
偏暖：像傍晚、咖啡馆、回忆
偏冷：像清晨、雨天、城市夜晚
颜色太乱：看起来脏、不统一
颜色舒服：画面更耐看
```

新手不需要一开始就学复杂调色。

先做到两件事就很好：

```text
1. 颜色不要明显偏得难看
2. 肤色看起来舒服自然
```

---

## 9.2 白平衡是什么

白平衡，英文是 White Balance，常写作 WB。

它的作用是：

```text
让白色看起来像白色，让整体颜色不要乱偏。
```

不同光源本身颜色不同：

```text
中午阳光：比较中性
清晨傍晚：偏暖、偏金黄
阴天：偏冷、偏蓝
普通灯泡：偏黄
荧光灯：可能偏绿
屏幕光：可能偏蓝
```

相机需要判断：现场的光到底是什么颜色？

如果判断准确，颜色就自然。

如果判断不准，照片就会偏色。

图像理解：

```text
白纸在阳光下：白色
白纸在黄灯下：看起来偏黄
白纸在阴天里：看起来偏蓝

白平衡的作用：告诉相机“这应该是白色”。
```

---

## 9.3 为什么照片会偏黄、偏蓝、偏绿

照片偏色通常是因为光源颜色不同，或者相机判断白平衡不准确。

### 9.3.1 偏黄

常见于：

```text
室内黄灯
餐厅
咖啡馆
夜晚路灯
傍晚阳光
```

偏黄不一定不好。

```text
轻微偏暖：温馨、有氛围
过度偏黄：皮肤蜡黄，白墙变黄，画面脏
```

### 9.3.2 偏蓝

常见于：

```text
阴天
清晨
阴影里
夜晚
相机白平衡偏冷
```

偏蓝也不一定不好。

```text
轻微偏冷：清爽、安静
过度偏蓝：脸色不好，看起来冷冰冰
```

### 9.3.3 偏绿

偏绿比较麻烦，常见于：

```text
办公室荧光灯
商场灯
地铁灯
一些 LED 灯
```

偏绿会让肤色很难看。

```text
脸色发灰、发绿、不健康
```

遇到偏绿环境，后期通常需要调色修正。

拍摄时可以尽量：

```text
换到窗边
关掉部分杂色灯
让一种主要光源照亮脸
```

---

## 9.4 常见白平衡模式怎么理解

相机里常见白平衡模式有这些。

```text
AWB 自动白平衡
日光
阴天
阴影
白炽灯
荧光灯
色温 K
自定义白平衡
```

### 9.4.1 AWB 自动白平衡

AWB 是自动白平衡。

```text
相机自动判断现场光线颜色
自动调整照片冷暖
```

新手阶段推荐先用 AWB。

```text
优点：方便、成功率高
缺点：有时会把氛围修得太中性，或者判断错复杂光线
```

### 9.4.2 日光、阴天、阴影

这些是预设模式。

```text
日光：适合晴天阳光
阴天：会让画面更暖一点
阴影：会比阴天更暖
```

为什么阴天模式会变暖？

因为阴天光线偏冷，相机会加一点暖色来抵消。

### 9.4.3 白炽灯和荧光灯

```text
白炽灯：用于偏黄的灯泡环境，会让画面变冷一点
荧光灯：用于某些偏绿灯光，会尝试修正颜色
```

现在很多 LED 灯颜色复杂，这些模式不一定每次都准。

### 9.4.4 色温 K

K 是 Kelvin，中文常叫“色温”。

数字越低，画面越冷；数字越高，画面越暖。

```text
3000K：偏冷，用来抵消黄灯
5000K：接近日光
6500K：偏暖，用来抵消阴天冷光
7500K：更暖
```

注意这里有点反直觉：

```text
相机里 K 值调高，照片会更暖。
相机里 K 值调低，照片会更冷。
```

新手暂时不需要频繁手动调 K，先知道它是控制冷暖的就好。

---

## 9.5 冷色、暖色和照片情绪

颜色不是越真实越好，有时候颜色是表达情绪的工具。

### 9.5.1 暖色适合什么

暖色通常让照片更亲近。

适合：

```text
日落
咖啡馆
家庭
情侣
食物
暖灯下的生活记录
秋天
```

感觉：

```text
温柔
怀旧
亲密
放松
```

### 9.5.2 冷色适合什么

冷色通常让照片更安静。

适合：

```text
清晨
雨天
夜晚城市
海边
雪景
极简画面
```

感觉：

```text
清爽
孤独
安静
理性
```

### 9.5.3 不要一张照片里颜色太乱

颜色太乱，画面会显得不高级。

比如：

```text
黄灯 + 绿灯 + 蓝屏幕 + 红招牌
```

这会让肤色和背景都很难看。

新手可以先练：

```text
一张照片里尽量有一个主要色调。
```

例如：

```text
绿色植物 + 白衣服
蓝天 + 浅色建筑
暖灯 + 木桌
灰墙 + 黑白衣服
```

---

## 9.6 拍人时肤色优先

拍人时，肤色通常比背景颜色更重要。

如果背景很好看，但脸色很怪，这张人像就会打折扣。

拍人时先看：

```text
脸有没有偏黄太重？
脸有没有发绿？
脸有没有太蓝、没有血色？
眼睛有没有光？
```

肤色舒服的常见条件：

```text
柔和光线
单一主要光源
不要混太多杂色灯
脸朝向光
曝光不要太暗
```

如果在餐厅或商场拍人，灯光复杂，脸色容易怪。

可以尝试：

```text
靠近窗边
找白墙反光
避开绿色或彩色灯
让脸靠近比较自然的光源
```

新手阶段记住：

```text
拍人时，先保脸色，再谈氛围。
```

---

## 9.7 RAW 和 JPEG 对颜色的影响

RAW 和 JPEG 对颜色后期空间不同。

```text
JPEG：相机已经把颜色处理好了
RAW：保留更多原始信息，后期更能调整颜色
```

如果白平衡拍错了：

```text
JPEG：也能调，但空间小，容易画质变差
RAW：更容易把偏黄、偏蓝拉回来
```

所以建议：

```text
重要照片：RAW + JPEG
日常随拍：JPEG 也可以
想认真修图：一定保留 RAW
```

RAW 的好处不是让你必须修图，而是给你留后路。

---

## 9.8 新手色彩建议

新手阶段，不要急着追求复杂调色。

先做到以下几点：

```text
白平衡先用 AWB
拍人看肤色
避免混合杂色光
颜色不要过度饱和
一张照片尽量有主色调
重要照片用 RAW + JPEG
```

如果你觉得照片颜色不好看，先检查：

```text
是不是光线太差？
是不是灯光颜色太杂？
是不是人脸偏绿或偏黄？
是不是背景颜色太抢？
是不是饱和度太高？
```

颜色舒服，常常来自简单：

```text
干净的光 + 干净的背景 + 不乱的颜色
```

---

## 9.9 这一章的小抄

白平衡：

```text
控制照片冷暖，让颜色不要乱偏。
```

常见偏色：

```text
黄灯：容易偏黄
阴天/阴影：容易偏蓝
荧光灯/商场灯：容易偏绿
```

新手设置：

```text
日常先用 AWB 自动白平衡
重要照片用 RAW + JPEG
拍人优先看肤色
```

色彩情绪：

```text
暖色：温柔、生活、亲近
冷色：安静、清爽、距离感
```

实用口诀：

```text
拍人先看脸色，拍景先看氛围，颜色乱了先找光。
```

## 9.10 本章练习

### 练习一：同一场景，不同白平衡

找一个室内场景或窗边场景。

分别拍：

```text
AWB 自动白平衡
日光
阴天
白炽灯
```

观察：

```text
哪张偏暖？
哪张偏冷？
哪张最接近你眼睛看到的颜色？
哪张氛围最好？
```

### 练习二：黄灯和窗边光对比

拍同一个人或物体，分别在：

```text
室内黄灯下
窗边自然光下
```

观察：

```text
肤色有什么不同？
哪张颜色更舒服？
黄灯下有没有偏黄？
```

### 练习三：找主色调

找三个颜色比较简单的场景：

```text
绿色植物场景
蓝天或灰墙场景
暖灯或木桌场景
```

每个场景拍一张。

观察：

```text
颜色少一点时，照片是不是更干净？
主体是不是更突出？
```

### 练习四：RAW + JPEG 对比

如果相机已经设置 RAW + JPEG，可以拍一张偏黄或偏蓝的照片。

后期尝试调整白平衡。

观察：

```text
RAW 是不是更容易拉回正常颜色？
JPEG 调整后是不是更容易画质变差？
```

# 第十章 拍摄模式和相机设置

这一章开始把前面学过的概念放到相机操作里。

你会在相机上看到这些模式：

```text
Auto / P / A / S / M
```

新手先记一句话：

```text
日常拍摄先练 A 档，因为它最适合理解光圈、虚化和画面效果。
```

---

## 10.1 拍摄模式是什么

拍摄模式就是：你和相机怎么分工。

```text
有些模式：相机决定大部分事情
有些模式：你决定一部分，相机帮你算剩下的
有些模式：所有重要参数都由你决定
```

主要参数还是那三个：

```text
光圈：背景虚不虚，进光多少
快门：动作清不清楚，进光多久
ISO：画面增亮多少，噪点多少
```

不同模式，就是决定谁来控制这些参数。

---

## 10.2 P、A、S、M 分别是什么

### 10.2.1 Auto 自动模式

Auto 模式就是相机全自动。

```text
相机决定光圈
相机决定快门
相机决定 ISO
相机决定很多其他设置
```

优点：

```text
方便
不需要想太多
适合临时记录
```

缺点：

```text
你不容易控制背景虚化
你不容易控制快门速度
你不知道相机为什么这样拍
```

Auto 可以用，但如果想学摄影，不能一直停在 Auto。

### 10.2.2 P 档 程序自动

P 档比 Auto 稍微自由一点。

```text
相机自动选择光圈和快门
你通常可以控制 ISO、曝光补偿、白平衡等
```

适合：

```text
快速记录
不想错过瞬间
对虚化和运动要求不高的场景
```

但 P 档仍然不是最适合学习画面控制的模式。

### 10.2.3 A 档 光圈优先

A 档是新手最推荐练的模式。

意思是：

```text
你决定光圈
相机决定快门
ISO 可以自动
```

你只需要先想：

```text
我想背景虚一点，还是整张清楚一点？
```

然后选择光圈。

```text
想虚化：用最大光圈
想风景清楚：用 F8 左右
想日常稳妥：用 F4-F5.6
```

A 档很适合：

```text
人像
旅行
街拍
静物
风景
日常记录
```

### 10.2.4 S 档 快门优先

S 档是快门优先。

意思是：

```text
你决定快门
相机决定光圈
ISO 可以自动
```

适合你最关心“动作”的时候。

```text
拍小孩跑动
拍宠物
拍运动
拍车流
拍水流
拍追随拍摄
```

比如：

```text
想把动作拍清楚：1/500s、1/1000s
想拍运动拖影：1/30s、1/15s
想拍水流丝滑：1/2s、1s
```

### 10.2.5 M 档 手动模式

M 档就是手动模式。

```text
你决定光圈
你决定快门
你决定 ISO，或者 ISO 也可以自动
```

M 档不是高手专属，也不是新手不能用。

但它需要你同时理解光圈、快门、ISO。

适合：

```text
光线稳定的棚拍
夜景长曝光
闪光灯拍摄
想完全固定曝光的场景
```

新手不用急着一开始就用 M 档。

```text
先用 A 档理解光圈
再用 S 档理解快门
最后再学 M 档会自然很多
```

---

## 10.3 新手为什么推荐先用 A 档

A 档最适合新手，是因为它把问题简化了。

你不用同时控制所有东西，只要先问：

```text
这张照片，我想要背景虚，还是前后都清楚？
```

然后选择光圈。

### 10.3.1 想拍人像

```text
模式：A 档
光圈：最大光圈
ISO：Auto
对焦：AF-C + 人眼识别
快门：注意不要低于 1/125s 或 1/250s
```

结果：

```text
背景更容易虚
人物更突出
相机帮你处理快门和 ISO
```

### 10.3.2 想拍风景

```text
模式：A 档
光圈：F8 左右
ISO：100-400 或 Auto
对焦：对主体或中远处
快门：如果太慢，要拿稳或用三脚架
```

结果：

```text
前后更容易都清楚
画面细节更完整
```

### 10.3.3 想拍日常

```text
模式：A 档
光圈：F4-F5.6
ISO：Auto
对焦：AF-C
```

结果：

```text
成功率高
不用频繁思考
画面也有一定控制感
```

---

## 10.4 什么时候用 S 档

当你最关心快门速度时，用 S 档。

比如你想控制：

```text
动作清不清楚
水流丝不丝滑
车灯有没有光轨
背景有没有速度感
```

常用例子：

```text
走动的人：1/250s
小孩宠物：1/500s
运动抓拍：1/1000s
追随拍摄：1/30s 到 1/125s
水流：1/2s 或更慢
车灯光轨：1s 到 10s
```

S 档注意事项：

```text
快门越快，进光越少
环境太暗时，ISO 会升高
如果光线仍然不够，照片可能偏暗
```

---

## 10.5 M 档什么时候再学

M 档不是必须马上学。

等你对下面这些问题有感觉了，再学 M 档会轻松很多：

```text
光圈变大，画面会怎样？
快门变慢，画面会怎样？
ISO 变高，画面会怎样？
曝光补偿什么时候加，什么时候减？
```

M 档适合这些场景：

```text
夜景长曝光
烟花
星空
闪光灯
棚拍
固定光线下连续拍摄
```

有些人会说“专业就要用 M 档”。

这不完全对。

```text
会选择合适模式，比一直用 M 档更重要。
```

日常拍摄里，很多熟练摄影师也常用 A 档。

---

## 10.6 Auto ISO 和最低快门

Auto ISO 是新手非常好用的功能。

意思是：

```text
相机根据光线自动调整 ISO。
```

但 Auto ISO 最好配合“最低快门速度”理解。

因为拍人时，你不希望相机为了降低 ISO，把快门降得太慢。

例如：

```text
室内拍人
相机为了 ISO 低，把快门降到 1/30s
结果人糊了
```

更好的思路：

```text
告诉相机：快门尽量不要低于 1/125s 或 1/250s
如果光线不够，就提高 ISO
```

新手可以先记：

```text
拍静止人像：最低快门 1/125s
拍走动的人：最低快门 1/250s
拍小孩宠物：最低快门 1/500s
```

如果暂时不会设置最低快门，也没关系。

你可以先学会观察屏幕上的快门数字：

```text
看到 1/30s、1/60s：拍人要小心
看到 1/125s：静止人像基本可用
看到 1/250s：日常抓拍更稳
```

## 10.7 日常拍摄推荐设置

在真正进入相机菜单之前，可以先有一个目标设置。

日常推荐：

```text
模式：A 档
ISO：Auto
对焦模式：AF-C
识别目标：人
对焦区域：广域或跟踪
白平衡：AWB
文件格式：RAW + JPEG
```

拍摄时主要看三个东西：

```text

快门：不能太慢
ISO：可以自动升高
```

日常拍摄流程：

```text
1. 先看光线
2. 决定主体
3. 选择焦距
4. 选择光圈
5. 看快门够不够快
6. 确认对焦在人眼或主体上
7. 按快门
```

## 10.9 这一章的小抄

拍摄模式：

```text
Auto：相机全自动，适合临时记录
P：程序自动，比 Auto 稍自由
A：光圈优先，你控制光圈，相机算快门
S：快门优先，你控制快门，相机算光圈
M：手动模式，你控制光圈、快门、ISO
```

新手推荐顺序：

```text
先熟练 A 档
需要控制运动时用 S 档
最后再系统学习 M 档
```

日常推荐：

```text
A 档 + Auto ISO + AF-C + 人眼识别 + AWB
```

拍摄时看这几个数字：

```text
光圈：决定虚化
快门：决定糊不糊
ISO：决定噪点和亮度
```

实用口诀：

```text
人像 A 档开大光圈，运动 S 档定快门，日常 Auto ISO 放心用。
```

# 第十一章 实战场景参数

这一章是实战速查。

前面我们学了光圈、快门、ISO、焦距、对焦、构图、光线、白平衡和拍摄模式。真正拍照时，不需要每次都从头想一遍，可以先用场景模板快速开始。

新手先记一句话：

```text
先用一个稳妥设置拍到，再根据画面问题微调。
```

---

## 11.1 实战设置的核心思路

拍照时可以按这个顺序想：

```text
1. 我拍什么？人、景、物、运动、夜景？
2. 我想要什么效果？背景虚、全清楚、动作凝固、运动拖影？
3. 先选模式：A 档还是 S 档？
4. 再选焦距：28、50、100、200 附近？
5. 再看快门够不够快。
6. 最后让 ISO 自动补亮。
```

简单判断：

```text
想控制虚化：用 A 档
想控制动作：用 S 档
想省心记录：A 档 + Auto ISO
```

你的 28-200mm 镜头非常适合用“场景模板”拍摄，因为它覆盖了广角到长焦。

```text
28mm：风景、环境、室内
50mm：日常、街拍、自然视角
85-135mm：人像、物件、细节
200mm：远处、舞台、压缩感、特写
```

---

## 11.2 日常万能设置

如果你不知道今天会拍什么，可以先用这一套。

```text
模式：A 档
光圈：F4-F5.6
ISO：Auto
对焦：AF-C
对焦区域：广域或跟踪
识别目标：人
白平衡：AWB
文件格式：RAW + JPEG
```

适合：

```text
出门散步
旅行记录
朋友聚会
街边随拍
室内日常
```

拍摄时看两个数字：

```text
快门不要太慢
ISO 高一点不用慌
```

如果拍人发现背景不够虚：

```text
把焦距拉到 85-135mm
光圈开到最大
让人离背景远一点
```

如果拍风景发现前后不够清楚：

```text
光圈收小到 F8
焦距用 28-50mm
```

## 11.3 人像怎么设置

### 11.3.1 半身人像

半身人像是最容易拍好看的练习题。

推荐：

```text
模式：A 档
焦距：85-135mm
距离：大约 2-4 米，根据构图前后移动
光圈：最大光圈，或 F4
ISO：Auto
快门：尽量不低于 1/125s，最好 1/250s
对焦：AF-C + 人眼识别
白平衡：AWB
```

拍摄重点：

```text
眼睛清楚
背景干净
人离背景远一点
找柔光或侧光
```

如果背景太乱：

```text
换角度
用更长焦
靠近人物
让人物离背景远一点
```

### 11.3.2 全身人像

全身人像比半身更考验背景和姿态。

推荐：

```text
模式：A 档
焦距：50-100mm
距离：根据全身构图后退，85mm 大约 4-6 米常见
光圈：最大光圈到 F5.6
ISO：Auto
快门：1/250s 左右更稳
对焦：人眼或人脸
```

拍摄重点：

```text
脚不要贴着画面底部
头顶不要留太多空
背景线条不要穿过头部
人往哪里看，就给哪里留空间
```

### 11.3.3 环境人像

环境人像是“人 + 地点故事”。

推荐：

```text
模式：A 档
焦距：28-50mm
光圈：F4-F8
ISO：Auto
快门：1/125s 或更快
对焦：人脸或人眼
```

适合：

```text
旅行打卡
街头人像
咖啡馆
展览
城市建筑前
```

重点：

```text
环境要服务人物，不要把人物淹没。
```

## 11.4 风景和旅行怎么设置

风景通常希望前后都清楚。

推荐：

```text
模式：A 档
焦距：28-50mm
光圈：F8 左右
ISO：100-400 或 Auto
快门：手持时注意不要太慢
对焦：主体或画面中远处
白平衡：AWB 或日光
```

拍摄重点：

```text
地平线要平
边缘不要乱
前景、中景、背景有层次
光线比参数更重要
```

旅行时可以用两个焦段快速切换：

```text
28mm：拍大环境
70-135mm：拍局部细节
```

比如：

```text
28mm 拍整条街
100mm 拍窗户、招牌、远处的人
200mm 拍建筑细节或远处山峰
```

## 11.5 街拍和抓拍怎么设置

街拍最怕错过瞬间，所以设置要稳、反应要快。

推荐：

```text
模式：A 档
焦距：35-70mm
光圈：F4-F8
ISO：Auto
快门：尽量 1/250s 或更快
对焦：AF-C + 广域/跟踪
白平衡：AWB
```

如果人走得快，或者你也在走：

```text
快门尽量 1/250s 到 1/500s
```

街拍重点：

```text
提前观察光线
等人走进画面
背景先选好，再等主体出现
不要只追着人拍
```

一个好用方法：

```text
先找一个好背景
再等待有趣的人或动作进入画面
```

## 11.6 室内、咖啡馆、餐厅怎么设置

室内光线通常比你以为的暗。

推荐：

```text
模式：A 档
焦距：35-85mm
光圈：最大光圈到 F4
ISO：Auto
快门：拍人不低于 1/125s，最好 1/250s
对焦：AF-C + 人眼识别
白平衡：AWB
```

拍摄重点：

```text
找窗边光
避开头顶强灯
避免脸被黄灯、绿灯照得太奇怪
背景不要太乱
```

拍食物或咖啡：

```text
焦距：50-100mm
光圈：最大光圈到 F4
角度：侧光更有质感
对焦：对最漂亮的细节
```

如果 ISO 升到 3200 或 6400：

```text
不用紧张，室内很正常。
人清楚比 ISO 低更重要。
```

## 11.7 夜景手持怎么设置

夜景手持的核心是：不要让快门慢到手抖。

推荐：

```text
模式：A 档
焦距：28-50mm 更容易稳
光圈：最大光圈
ISO：Auto
快门：尽量不低于 1/60s，拍人尽量 1/125s 以上
对焦：AF-C 或 AF-S 都可，拍人用人眼识别
白平衡：AWB
```

拍摄重点：

```text
找有光的地方
身体站稳
屏住呼吸轻按快门
多拍几张
接受高 ISO
```

如果拍夜晚人像：

```text
让人靠近灯光
不要站在完全黑的地方
用 50-100mm 更自然
快门尽量 1/125s 或更快
```

如果想拍车灯光轨：

```text
模式：S 档或 M 档
快门：1s 到 10s
ISO：低 ISO
三脚架：需要
```

```text

```

# 第十二章 回看照片和复盘

这一章学习“复盘”。

很多新手拍完照片，只会说：

```text
这张好看
这张不好看
```

但真正进步，需要进一步知道：

```text
为什么好看？
为什么不好看？
下一张该改什么？
```

新手先记一句话：

```text
复盘不是挑毛病，而是找到下一张照片的改进方向。
```

---

## 12.1 为什么要复盘

拍照时现场很忙，你要看光、看人、看构图、看参数，很难一次全部做好。

拍完以后回看，反而更容易冷静判断问题。

复盘可以帮你发现：

```text
照片是不是糊了
焦点是不是对错了
曝光是不是太亮或太暗
背景是不是太乱
主体是不是太小
光线是不是不好看
颜色是不是偏得难受
焦距是不是选得不合适
```

每次只要找到一个主要问题，下次就会进步。

```text
一次改一个问题，比一次想改所有问题更有效。
```

---

## 12.2 先看照片是否清楚

回看照片第一步，先看清楚不清楚。

尤其拍人时，放大看眼睛。

```text
拍人：看眼睛
拍动物：看眼睛
拍物件：看关键细节
拍风景：看主体和远处细节
```

如果不清楚，先判断是哪一种不清楚。

### 12.2.1 焦点对错了

表现：

```text
人眼不清楚，但背景清楚
脸不清楚，但衣服清楚
主体不清楚，旁边物体清楚
```

原因可能是：

```text
对焦点跑到背景
没有启用人眼识别
主体太小，相机识别错了
点对焦没有放准
```

改进：

```text
拍人用 AF-C + 人眼识别
确认小框在眼睛或脸上
主体太小时靠近一点
必要时用点对焦指定主体
```

### 12.2.2 快门太慢糊了

表现：

```text
整张照片发虚
人有拖影
手部、头发、走路动作模糊
背景可能清楚但主体糊
```

原因可能是：

```text
快门太慢
焦距太长但快门不够快
主体在动
你手持不够稳
```

改进：

```text
拍静止人像至少 1/125s
拍走动的人至少 1/250s
拍小孩宠物 1/500s 起
200mm 手持尽量 1/400s 起
```

---

## 12.3 再看曝光是否合适

曝光就是照片亮不亮。

常见问题有三种：

```text
太暗
太亮
主体和背景亮度差太大
```

### 12.3.1 照片太暗

表现：

```text
人脸黑
暗部没有细节
整体灰沉
```

可能原因：

```text
逆光时相机被亮背景骗了
曝光补偿太低
环境光线太差
ISO 或快门设置不合适
```

改进：

```text
加曝光补偿，比如 +0.3 到 +1.0
让人脸转向光
换到更亮的位置
必要时提高 ISO
```

### 12.3.2 照片太亮

表现：

```text
天空一片白
脸上高光没有细节
白衣服糊成一片
```

可能原因：

```text
曝光补偿太高
光线太强
相机测光偏亮
```

改进：

```text
降低曝光补偿，比如 -0.3 到 -1.0
换到阴影里
避开正午强光
```

### 12.3.3 背景亮，人脸暗

这是逆光人像常见问题。

表现：

```text
背景好看，人脸很黑
```

改进：

```text
加曝光补偿
让人脸转向侧光
不要让太阳或亮窗户占画面太大
靠近人物拍
```

---

## 12.4 再看主体是否突出

照片清楚、亮度也对，但仍然不好看，常常是主体不突出。

表现：

```text
不知道该看哪里
主体太小
背景太抢眼
画面里元素太多
```

改进方法：

```text
靠近主体
用更长焦段
用更大光圈
让主体离背景远一点
换角度避开杂物
裁掉不重要的部分
```

判断主体是否突出，可以问：

```text
别人第一眼会看我想让他看的地方吗？
```

如果答案是否定的，就说明主体还不够明确。

---

## 12.5 再看光线和颜色

光线和颜色决定照片质感。

### 12.5.1 光线不好

表现：

```text
脸上阴影乱
眼窝黑
顶光很重
画面灰
主体没有光
```

改进：

```text
找窗边光
找阴影里的柔光
清晨或傍晚拍
让主体转向光
避开正午直射太阳
```

### 12.5.2 颜色不好

表现：

```text
脸太黄
脸发绿
画面太蓝
颜色很杂乱
```

改进：

```text
白平衡先用 AWB
避开混合杂色光
拍人优先看肤色
使用 RAW + JPEG 保留后期空间
让一种主要光源照亮主体
```

复盘时记住：

```text
颜色问题很多时候不是相机问题，而是光源太乱。
```

---

## 12.6 再看构图和边缘

构图问题常常不是主体本身，而是画面边缘和背景细节。

检查顺序：

```text
主体位置舒服吗？
头顶空间是不是太多？
有没有切到关节？
画面边缘有没有杂物？
地平线是不是歪了？
背景线条有没有穿过头部？
人往哪里看，有没有留空间？
```

常见改进：

```text
打开网格线
用三分法重新放主体
拍人时眼睛靠近上三分线
裁掉边缘杂物
横拍竖拍都试一张
换一个更干净的背景
```

一个很实用的习惯：

```text
按快门前，看一眼画面四个角。
```

---

## 12.7 用参数倒推问题

照片文件里通常能看到 EXIF 参数，比如焦距、光圈、快门、ISO。

这些参数可以帮你倒推问题。

### 12.7.1 看快门

```text
拍人用了 1/30s：很可能糊
200mm 用了 1/60s：很可能手抖
小孩跑动用了 1/125s：很可能动作糊
```

改进：

```text
提高快门
用 S 档固定快门
让 Auto ISO 升高
```

### 12.7.2 看光圈

```text
人像用了 F8：背景可能不够虚
多人合照用了 F2.8：可能有人不清楚
风景用了最大光圈：前后可能不够清楚
```

改进：

```text
人像想虚化：开大光圈
风景想全清楚：F8 左右
多人合照：F5.6-F8 更稳
```

### 12.7.3 看 ISO

```text
ISO 很高：说明现场光线暗，或快门很快
ISO 很低但照片糊：可能为了低 ISO 牺牲了快门
```

改进：

```text
不要怕 ISO 升高
清楚优先于干净
```

### 12.7.4 看焦距

```text
28mm 近距离拍人：脸可能变形
50mm 拍全身：比较自然
100mm 拍半身：更容易好看
200mm 拍暗光：快门和 ISO 压力更大
```

改进：

```text
人像多试 85-135mm
环境人像用 28-50mm
远处细节用 150-200mm
```

## 12.8 常见失败照片诊断表

```text
问题：整张都糊
可能原因：快门太慢 / 手抖
改进：提高快门，拿稳相机，长焦时更要快

问题：背景清楚，人不清楚
可能原因：对焦到背景
改进：人眼识别，确认焦点框，靠近主体

问题：人有拖影
可能原因：主体动了，快门不够快
改进：1/250s、1/500s 或更快

问题：背景不够虚
可能原因：焦距短 / 光圈小 / 人离背景近
改进：长焦，大光圈，靠近主体，背景远

问题：人脸太暗
可能原因：逆光 / 背景太亮
改进：加曝光补偿，让脸转向光，换角度

问题：照片很吵、噪点多
可能原因：ISO 高，环境暗
改进：找更好的光；如果人清楚，噪点可接受

问题：颜色偏黄
可能原因：黄灯 / 白平衡偏暖
改进：AWB，换自然光，后期调白平衡

问题：颜色偏绿
可能原因：荧光灯 / 商场灯
改进：避开杂色灯，靠窗，后期校正

问题：画面乱
可能原因：背景杂物多 / 主体不明确
改进：靠近、换角度、清理背景、用长焦

问题：照片平淡
可能原因：光线平、主体弱、构图普通
改进：找侧光、等更好时机、强化主体
```

## 12.9 这一章的小抄

复盘顺序：

```text
1. 清楚吗？
2. 亮度对吗？
3. 主体突出吗？
4. 光线好看吗？
5. 颜色舒服吗？
6. 构图干净吗？
7. 参数说明了什么？
```

最常见问题对应：

```text
糊：先看快门
不清楚：先看对焦
不虚：看焦距、光圈、距离、背景距离
太暗太亮：看曝光补偿和光线
颜色怪：看白平衡和光源
不好看：看光线、主体、背景和构图
```

实用口诀：

```text
先查清晰，再查亮度；再看主体，最后看光和构图。
```

# 第十三章 下一阶段练习路线

这一章不是新概念，而是把前面学过的内容变成练习计划。

学摄影最怕一种情况：

```text
概念都看懂了，但拿起相机还是不知道拍什么、怎么调。
```

所以接下来要做的是：少量、重复、有目标地练。

新手先记一句话：

```text
每次只练一个重点，比一次想练所有东西更有效。
```

---

## 13.1 为什么需要练习路线

摄影不是只靠看懂概念就会的，它需要让眼睛和手形成习惯。

你需要练三件事：

```text
眼睛：看光线、看背景、看主体
脑子：知道该用什么焦距、光圈、快门
手：能快速调整相机，不错过画面
```

练习路线的目的不是让你每天拍大片，而是让你慢慢形成直觉。

比如看到一个人，你会自然想到：

```text
用 85-135mm
开大光圈
对眼睛
看快门够不够
让人离背景远一点
```

看到一个风景，你会自然想到：

```text
用 28-50mm
F8 左右
地平线要平
找前景、中景、背景
等更好的光
```

这就是练习的价值。

---

## 13.2 7 天基础练习计划

这是一条适合新手的 7 天路线。每天只练一个重点，每次 20-40 分钟就可以。

### 第 1 天：焦距练习

目标：理解 28mm、50mm、100mm、200mm 的画面差异。

练习：

```text
找一个固定主体，比如人、杯子、花、包。
分别用 28mm、50mm、100mm、200mm 拍。
尽量让主体大小接近，每次改变焦距后自己前后移动。
```

观察：

```text
背景多少有什么变化？
人物脸型有没有变化？
哪一个焦段最适合这个主体？
```

今天只记：

```text
28 看环境，50 看日常，100 看人，200 看细节。
```

### 第 2 天：光圈和虚化练习

目标：理解光圈、焦距、距离如何影响背景虚化。

练习：

```text
用 70-135mm 拍一个小物件或人像。
分别拍最大光圈、F5.6、F8。
再试一次：主体贴近背景 vs 主体远离背景。
```

观察：

```text
光圈变小后，背景是不是更清楚？
主体离背景远后，虚化是不是更明显？
```

今天只记：

```text
大光圈 + 长焦 + 靠近主体 + 背景远。
```

### 第 3 天：快门练习

目标：知道什么快门能拍清楚动作。

练习：

```text
找一个走动的人，或拍路上的车。
用 1/60s、1/125s、1/250s、1/500s 分别拍。
```

观察：

```text
动作什么时候开始清楚？
快门越快，ISO 有没有升高？
```

今天只记：

```text
拍人不动 1/125s，走动 1/250s，小孩宠物 1/500s。
```

### 第 4 天：ISO 练习

目标：不要害怕 ISO，理解清楚比干净更重要。

练习：

```text
在室内拍一个人或物体。
试一张低 ISO 慢快门。
再试一张高 ISO 快快门。
```

观察：

```text
哪一张更清楚？
哪一张噪点更多？
你更愿意保留哪一张？
```

今天只记：

```text
宁愿有点噪点，也不要把照片拍糊。
```

### 第 5 天：对焦练习

目标：拍人时确认眼睛清楚。

练习：

```text
拍一个人或玩偶。
分别对眼睛、衣服、背景拍三张。
再用 AF-C + 人眼识别拍几张。
```

观察：

```text
眼睛清楚时，照片是不是更有精神？
相机有没有把焦点框放到眼睛上？
```

今天只记：

```text
拍人优先对眼睛。
```

### 第 6 天：构图和背景练习

目标：让主体更明确、背景更干净。

练习：

```text
拍同一个主体三张。
第 1 张：随手拍。
第 2 张：靠近一点。
第 3 张：换角度，让背景更干净。
```

观察：

```text
哪一张主体最明确？
哪一张背景最不干扰？
画面边缘有没有杂物？
```

今天只记：

```text
构图不是拍进更多，而是去掉干扰。
```

### 第 7 天：光线练习

目标：开始看懂顺光、侧光、逆光和柔光。

练习：

```text
找一个人或物件。
分别用顺光、侧光、逆光拍。
再找直射硬光和阴影柔光各拍一张。
```

观察：

```text
哪张更立体？
哪张皮肤或物体更舒服？
逆光时主体有没有变暗？
```

今天只记：

```text
拍人先找柔光，拍物先找侧光。
```

## 13.3 14 天进阶练习计划

如果 7 天练完以后还想继续，可以用 14 天计划加强实战。

```text
第 1 天：四焦段练习
第 2 天：光圈虚化练习
第 3 天：快门凝固动作练习
第 4 天：慢快门运动感练习
第 5 天：ISO 暗光练习
第 6 天：人眼对焦练习
第 7 天：构图和背景练习
第 8 天：窗边光人像练习
第 9 天：街拍等待练习
第 10 天：室内咖啡馆或餐厅练习
第 11 天：风景 F8 练习
第 12 天：夜景手持练习
第 13 天：人像 85-135mm 练习
第 14 天：选 10 张照片复盘
```

### 第 8 天：窗边光人像

```text
找窗户侧前方的柔光。
用 85-135mm，最大光圈或 F4。
让人物脸稍微转向窗户。
```

重点：

```text
眼睛有光，脸上阴影柔和。
```

### 第 9 天：街拍等待

```text
先找一个好背景。
不要急着拍，等人走进画面。
用 35-70mm，F4-F8，1/250s 以上。
```

重点：

```text
背景先成立，再等主体出现。
```

### 第 10 天：室内日常

```text
在咖啡馆、餐厅或家里拍。
找窗边光或干净的灯光。
拍人、食物、杯子各一张。
```

重点：

```text
避开杂色灯，ISO 高一点没关系。
```

### 第 11 天：风景 F8

```text
用 28-50mm。
光圈 F8。
注意地平线、前景、中景、背景。
```

重点：

```text
整张清楚，画面有层次。
```

### 第 12 天：夜景手持

```text
用 28-50mm。
最大光圈，Auto ISO。
身体站稳，多拍几张。
```

重点：

```text
找有光的地方，不要站在完全黑的地方拍。
```

### 第 13 天：人像焦段

```text
用 85mm、100mm、135mm、200mm 分别拍人像。
```

观察：

```text
哪个焦段脸型最好看？
哪个焦段背景最舒服？
哪个焦段最难稳定？
```

### 第 14 天：复盘

选 10 张照片，分别写一句：

```text
这张最好的地方是什么？
这张最大的问题是什么？
下一次我只改哪一点？
```

## 13.4 每次出门拍摄的任务卡

出门前可以只给自己一个小任务。

不要每次都想“我要拍大片”，可以想：

```text
今天只练焦距
今天只练背景干净
今天只练窗边光
今天只练 85mm 人像
今天只练快门不要糊
今天只练三分法
今天只练复盘 5 张照片
```

任务越小，越容易完成。

### 日常任务卡

```text
模式：A 档
ISO：Auto
对焦：AF-C
白平衡：AWB
目标：拍 10 张主体明确的照片
复盘：选 3 张最好和 3 张最差
```

### 人像任务卡

```text
焦距：85-135mm
光圈：最大光圈或 F4
快门：1/125s 以上，走动 1/250s
对焦：人眼
目标：眼睛清楚，背景干净
```

### 风景任务卡

```text
焦距：28-50mm
光圈：F8
ISO：100-400 或 Auto
目标：地平线平，前中后景有层次
```

### 夜景任务卡

```text
焦距：28-50mm
光圈：最大光圈
ISO：Auto
目标：不要手抖，找有光的主体
```

---

## 13.5 如何建立自己的照片复盘习惯

建议你每次拍完，不要复盘所有照片，只选少量。

```text
选 3 张最喜欢的
选 3 张最不满意的
```

对每张照片只写一句话。

### 喜欢的照片写什么

```text
我喜欢它哪里？
是光线好？构图好？表情好？背景干净？焦段舒服？
```

### 不满意的照片写什么

```text
最大问题是什么？
是糊了？对错焦？太暗？背景乱？颜色怪？主体太小？
```

### 下一次只改一个点

不要写太多目标。

例如：

```text
下次拍人，我只注意眼睛清楚。
下次拍街景，我只注意背景干净。
下次拍夜景，我只注意快门不要太慢。
```

这会比“下次全部都拍好”更有效。

---

## 13.6 这一章的小抄

练习原则：

```text
一次只练一个重点
每次拍完做小复盘
先拍到，再拍好
先清楚，再好看
```

7 天基础路线：

```text
第 1 天：焦距
第 2 天：光圈
第 3 天：快门
第 4 天：ISO
第 5 天：对焦
第 6 天：构图
第 7 天：光线
```

每次出门的简单流程：

```text
定一个小任务
拍 20-50 张
选 3 张喜欢的
选 3 张不满意的
每张只写一句复盘
下一次只改一个问题
```

最终目标：

```text
看到画面时，能自然想到焦距、光圈、快门、ISO、对焦、光线和构图。
```

# 第十四章 上手操作相机

这一章开始真正上手相机。

前面的章节是在理解概念，这一章的目标是：让你拿起相机后，能先设置出一套稳定、适合新手学习的基础配置。

新手先记一句话：

```text
不要一开始就追求所有菜单都懂，先把最常用的 5 个设置用熟。
```

这 5 个设置是：

```text
A 档
Auto ISO
AF-C
人眼识别
RAW + JPEG
```

---

## 14.1 上手前先统一目标

第一次设置相机，不是为了变专业，而是为了提高成功率。

我们希望相机先进入一个“日常稳妥状态”：

```text
能拍人
能拍日常
能拍旅行
能拍室内
能拍清楚
有一定虚化
后期还有空间
```

所以这一章不追求复杂菜单，只追求能开始拍。

基础目标：

```text
你控制光圈
相机帮你处理快门和 ISO
相机帮你识别人眼
照片同时保存 JPEG 和 RAW
```

这样你既能学习控制画面，又不会被参数淹没。

---

## 14.2 第一次推荐基础设置

如果你只想先设置一套能用的，可以按下面这个来。

```text
拍摄模式：A 档
ISO：Auto
对焦模式：AF-C
对焦区域：广域 或 跟踪
识别目标：人
眼部识别：开启
白平衡：AWB
文件格式：RAW + JPEG
连拍：低速或单张都可以
测光：多重
```

这套设置适合：

```text
人像
旅行
日常
街拍
室内自然光
咖啡馆
普通风景
```

它不是所有场景最完美的设置，但非常适合作为新手默认起点。

---

## 14.3 设置 A 档并理解屏幕参数

A 档也叫光圈优先。

```text
你决定光圈，相机决定快门。
```

在相机顶部或模式转盘上，把模式调到：

```text
A
```

进入 A 档后，你主要看屏幕上的三个数字：

```text
F 数字：光圈
1/xxx：快门
ISO：感光度
```

例如屏幕上可能显示：

```text
F4    1/250    ISO 800
```

意思是：

```text
光圈 F4
快门 1/250s
ISO 800
```

你需要先学会读这三个数字。

### 14.3.1 A 档里怎么选光圈

日常可以这样选：

```text
拍人像：最大光圈 或 F4
拍物件：最大光圈 或 F4
拍日常：F4-F5.6
拍多人：F5.6-F8
拍风景：F8
夜晚手持：最大光圈
```

你的镜头是 28-200mm F2.8-5.6，所以最大光圈会随着焦距变化。

```text
28mm：最大约 F2.8
200mm：最大约 F5.6
```

如果你在 200mm 看到最大只能到 F5.6，这是正常的，不是相机坏了。

---

## 14.4 设置 Auto ISO

ISO 建议先设为 Auto。

意思是：

```text
相机会根据光线自动提高或降低 ISO。
```

新手先不要害怕 Auto ISO。

因为日常拍摄里，更重要的是：

```text
快门不要太慢
主体要清楚
```

如果环境变暗，相机自动把 ISO 提高，这是在帮你保住快门。

### 14.4.1 观察 Auto ISO

你可以做一个小测试：

```text
对着窗外：ISO 可能很低
对着室内：ISO 可能升高
对着暗角：ISO 可能更高
```

这说明 Auto ISO 在工作。

### 14.4.2 拍人时看快门

即使用 Auto ISO，你也要注意快门速度。

```text
拍静止人像：尽量 1/125s 以上
拍走动的人：尽量 1/250s 以上
拍小孩宠物：尽量 1/500s 以上
```

如果你看到快门变成：

```text
1/30s
1/60s
```

拍人就要小心了，可能会糊。

解决：

```text
开大光圈
找更亮的地方
提高 ISO 上限
让人少动
使用更短焦距
```

---

## 14.5 设置 AF-C 和人眼识别

拍人时，推荐用 AF-C。

```text
AF-C = 连续自动对焦
```

它会持续调整焦点，适合人轻微移动、走动、抓拍。

推荐：

```text
对焦模式：AF-C
识别目标：人
眼部识别：开启
对焦区域：广域 或 跟踪
```

拍摄时注意屏幕上的对焦框。

```text
小框在眼睛上：很好
小框在脸上：基本可以
小框在衣服或背景：要小心
```

拍人时的优先级：

```text
眼睛清楚 > 脸清楚 > 衣服清楚 > 背景清楚
```

如果相机总是对到背景：

```text
靠近人物
让人物在画面里更大
换成跟踪对焦
必要时用点对焦放在人脸上
```

---

## 14.6 设置 RAW + JPEG

建议设置为：

```text
RAW + JPEG
```

这样每次拍照会保存两份：

```text
JPEG：可以直接看、直接分享
RAW：保留更多信息，方便以后修图
```

为什么新手也建议保留 RAW？

```text
白平衡拍错了，RAW 更容易修
照片稍微太暗，RAW 更容易救
以后想认真修图，有原始底片
```

如果你只是随便记录，可以只用 JPEG。

但学习阶段，推荐 RAW + JPEG，因为它给你留后路。

注意：

```text
RAW + JPEG 会占用更多存储卡空间。
```

所以记得准备容量足够的存储卡。

---

## 14.7 设置白平衡和曝光补偿

### 14.7.1 白平衡

新手先用：

```text
AWB 自动白平衡
```

AWB 适合大多数日常场景。

如果照片颜色明显不舒服，再考虑调整。

```text
太黄：可能是黄灯影响
太蓝：可能是阴天或阴影
太绿：可能是荧光灯或商场灯
```

### 14.7.2 曝光补偿

曝光补偿是让照片整体更亮或更暗。

```text
+0.3 / +0.7 / +1.0：更亮
-0.3 / -0.7 / -1.0：更暗
```

常见用法：

```text
逆光人像人脸太暗：加一点曝光补偿
白衣服或天空太亮：减一点曝光补偿
夜景想保留氛围：可以略微减一点
```

新手先记：

```text
人脸太暗，加曝光补偿。
高光太亮，减曝光补偿。
```

---

## 14.8 第一次实拍流程

设置好以后，按这个流程拍第一组照片。

### 14.8.1 拍一个人

推荐：

```text
模式：A 档
焦距：85-135mm
光圈：最大光圈或 F4
ISO：Auto
对焦：AF-C + 人眼识别

```

拍摄步骤：

```text

2. 让人离背景远一点
3. 找柔光，比如窗边或阴影里

5. 看快门是否不低于 1/125s
6. 拍 5-10 张
```

### 14.8.2 拍一个物件

推荐：

```text

焦距：70-135mm

ISO：Auto
对焦：对最重要细节
```

拍摄步骤：

```text
1. 把物件放在窗边或干净桌面
2. 让光从侧面来
3. 背景留远一点
4. 对焦在最想展示的位置
5. 拍横竖各一张
```

### 14.8.3 拍一个风景或街景

推荐：

```text
模式：A 档
焦距：28-50mm
光圈：F8
ISO：Auto 或 100-400
对焦：主体或中远处
```

拍摄步骤：

```text
1. 打开网格线
2. 注意地平线
3. 检查画面四个角
4. 找前景、中景、背景
5. 拍一张横图，再拍一张竖图
```

## 14.9 拍完如何检查

拍完不要只看缩略图，要放大检查。

### 14.9.1 拍人检查

眼睛清楚吗？

### 14.9.3 拍风景检查

```text
地平线平吗？
主体明确吗？
前后是否都清楚？
画面边缘有没有乱入？
```

如果发现问题，现场马上重拍。

```text
现场重拍，比回家后后悔有效得多。
```

# 第十五章 人像实拍专题

这一章专门练人像。

你这支 28-200mm 镜头非常适合新手拍人，因为它既能拍环境人像，也能用 85-135mm 拍半身，还能用 200mm 拍出更强的背景压缩。

新手先记一句话：

```text
好看人像 = 眼睛清楚 + 光线舒服 + 背景干净。
```

---

## 15.1 人像先抓住三件事

拍人像时，不要一开始就想太复杂。

先抓三件事：

```text
1. 眼睛清楚
2. 光线柔和
3. 背景干净
```

如果这三件事做好，人像通常不会太差。

参数只是辅助：

```text
焦距帮助你选择画面感觉
光圈帮助你控制虚化
快门帮助你避免糊
ISO 帮你在暗光下保住亮度
```

---

## 15.2 半身人像怎么拍

半身人像是最适合新手练的人像类型。

推荐设置：

```text
模式：A 档
焦距：85-135mm
距离：大约 2-4 米
光圈：最大光圈或 F4
ISO：Auto
快门：1/125s 以上，最好 1/250s
对焦：AF-C + 人眼识别
白平衡：AWB
```

拍摄步骤：

```text
1. 找柔光，比如窗边、阴影、傍晚
2. 找干净背景
3. 让人离背景远一点
4. 用 85-135mm 构图
5. 确认对焦框在眼睛上
6. 拍几张横图和竖图
```

半身人像注意：

```text
眼睛靠近上三分线
头顶不要留太多空间
不要从手腕、手肘等关节处切掉
背景线条不要穿过头部
```

---

## 15.3 全身人像怎么拍

全身人像更考验构图和背景。

推荐设置：

```text
模式：A 档
焦距：50-100mm
距离：根据构图后退，85mm 常见约 4-6 米
光圈：最大光圈到 F5.6
ISO：Auto
快门：1/250s 左右更稳
对焦：人眼或人脸
```

拍摄重点：

```text
脚底不要贴着画面底部
头顶空间不要太多
背景要干净
人物姿态要自然
相机高度可以在腰部到胸口附近
```

如果想让腿显得更长：

```text
用竖拍
相机略低一点
不要用太广角近距离怼拍脸
注意不要夸张变形
```

---

## 15.4 环境人像怎么拍

环境人像不是只拍人，而是拍“人在某个地方”。

推荐设置：

```text
模式：A 档
焦距：28-50mm
光圈：F4-F8
ISO：Auto
快门：1/125s 或更快
对焦：人脸或人眼
```

适合：

```text
旅行
街头
咖啡馆
展览
城市建筑
自然风景
```

环境人像重点：

```text
环境要有信息，但不能抢走人物
人物不要太小
背景线条要舒服
人和环境要有关系
```

可以这样拍：

```text
28mm：人小一点，强调地点
35-50mm：人和环境更平衡
70mm：环境少一点，人更突出
```

---

## 15.5 人像常见问题

```text
问题：眼睛不清楚
改进：AF-C + 人眼识别，确认焦点框在眼睛上

问题：背景太乱
改进：换角度，用长焦，让人离背景远一点

问题：脸太暗
改进：让脸朝向光，加曝光补偿，避开强逆光

问题：脸变形
改进：不要用 28mm 近距离拍大头，多用 50mm 以上

问题：背景不够虚
改进：用 85-135mm 或 200mm，开大光圈，人离背景远

问题：人像很平
改进：找侧光或窗边光，不要只用正面平光
```

# 第十六章 旅行和街拍专题

旅行和街拍的重点是：快速、观察、取舍。

新手先记一句话：

```text
旅行拍故事，街拍等瞬间。
```

---

## 16.1 旅行拍什么

旅行不只是拍景点，也可以拍：

```text
大环境
建筑细节
路人和生活
同行的人
食物
交通工具
光影
招牌和文字
有地方感的小细节
```

一组旅行照片最好有变化：

```text
远景：交代地点
中景：交代活动
近景：交代细节
人像：交代情绪
```

---

## 16.2 街拍的基本方法

街拍不是乱扫街，而是先观察。

一个好用方法：

```text
先找好背景，再等人进入画面。
```

步骤：

```text
1. 找一块好光线
2. 找干净背景或有趣背景
3. 预先构图
4. 等人、车、动作进入画面
5. 快速拍几张
```

街拍常用设置：

```text
模式：A 档
焦距：35-70mm
光圈：F4-F8
ISO：Auto
快门：尽量 1/250s 以上
对焦：AF-C + 广域/跟踪
```

---

## 16.3 旅行焦段怎么用

你的 28-200mm 很适合旅行。

```text
28mm：大景、街道、室内、建筑
35-50mm：日常视角、同行的人、街拍
70-135mm：局部、人像、食物、细节
150-200mm：远处细节、压缩感、舞台、山峰
```

旅行时可以练一个组合：

```text
先用 28mm 拍全貌
再用 100mm 拍细节
最后用 50mm 拍同行的人
```

这样一组照片会更完整。

---

## 16.4 旅行和街拍设置模板

旅行万能：

```text
A 档 / F4-F5.6 / Auto ISO / AF-C / AWB
```

风景建筑：

```text
A 档 / 28-50mm / F8 / ISO 100-400 或 Auto
```

街头抓拍：

```text
A 档 / 35-70mm / F4-F8 / 1/250s 以上 / AF-C
```

远处细节：

```text
A 档 / 100-200mm / 最大光圈 / 快门注意别太慢
```

---

## 16.5 练习任务

```text
任务一：同一个地点拍 5 张，分别是全景、中景、细节、人像、光影。
任务二：先选背景，等待一个人进入画面再拍。
任务三：用 28mm 和 100mm 拍同一条街，比较故事感差异。
```

# 第十七章 室内、食物和静物专题

室内拍摄最重要的是光线和背景。

新手先记一句话：

```text
室内先找窗，食物先找侧光，静物先清背景。
```

---

## 17.1 室内拍摄先找光

室内通常比肉眼感觉更暗。

优先找：

```text
窗边光
白墙反光
干净的台灯光
柔和的室内光
```

避免：

```text
头顶强灯
黄灯、绿灯、屏幕光混在一起
背景杂物太多
```

推荐设置：

```text
模式：A 档
焦距：35-85mm
光圈：最大光圈到 F4
ISO：Auto
快门：拍人尽量 1/125s 以上
白平衡：AWB
```

---

## 17.2 食物怎么拍

食物照片重点是质感。

推荐：

```text
焦距：50-100mm
光圈：最大光圈到 F4
光线：侧光或侧逆光
对焦：最想吃、最有细节的位置
```

拍摄角度：

```text
平视：适合汉堡、杯子、蛋糕层次
45 度：最常用，接近日常视角
俯拍：适合桌面摆盘、多道菜
```

注意：

```text
桌面要干净
餐具边缘不要乱切
颜色不要太杂
食物不要被黄灯照得太脏
```

---

## 17.3 静物怎么拍

静物适合练光线、构图和虚化。

推荐步骤：

```text
1. 找窗边光
2. 清理背景
3. 放一个主体
4. 用 70-135mm
5. 开大光圈
6. 对焦在关键细节
```

静物可以拍：

```text
杯子
书
花
手表
相机
钥匙
香水
桌面小物
```

---

## 17.4 室内常见问题

```text
问题：照片糊
改进：提高快门，接受 ISO 升高

问题：颜色很黄
改进：靠窗，避开黄灯，后期调白平衡

问题：画面乱
改进：清理桌面，只留下主体和少量配角

问题：食物没质感
改进：用侧光，不要用正面平光
```

---

## 17.5 练习任务

```text
任务一：窗边拍一个杯子，分别用正面光、侧光、逆光。
任务二：拍一份食物，分别用平视、45 度、俯拍。
任务三：清理桌面，只用 3 个物品拍一张静物。
```

# 第十八章 夜景和弱光专题

夜景和弱光的核心是：找光、稳住、接受 ISO。

新手先记一句话：

```text
夜晚不是哪里黑拍哪里，而是哪里有光拍哪里。
```

---

## 18.1 夜景手持怎么拍

推荐设置：

```text
模式：A 档
焦距：28-50mm 更容易稳
光圈：最大光圈
ISO：Auto
快门：尽量不低于 1/60s，拍人不低于 1/125s
白平衡：AWB
```

拍摄技巧：

```text
身体站稳
双手夹紧
轻按快门
多拍几张
找灯光、橱窗、路灯、招牌作为光源
```

如果焦距到 200mm：

```text
快门尽量 1/400s 起
ISO 升高很正常
```

---

## 18.2 夜晚人像怎么拍

夜晚拍人，关键是脸上要有光。

推荐：

```text
让人靠近橱窗、路灯、招牌、室内窗光
不要站在完全黑的地方
用 50-100mm 比较自然
光圈开大
快门 1/125s 以上
人眼对焦
```

注意：

```text
脸上有光比背景漂亮更重要
避开绿色、杂乱的灯光
背景灯可以远一点，形成虚化光点
```

---

## 18.3 光轨和慢门

如果想拍车灯光轨或丝滑水流，需要慢快门。

推荐：

```text
模式：S 档或 M 档
快门：1s 到 10s
ISO：100-400
光圈：根据亮度调整
三脚架：建议使用
```

没有三脚架时：

```text
把相机放在稳定平台上
使用 2 秒自拍
避免按快门时震动
```

---

## 18.4 夜景常见问题

```text
问题：整张糊
改进：快门太慢，稳住相机或提高 ISO

问题：人脸黑
改进：让人靠近光源

问题：噪点多
改进：正常现象；先保证清楚

问题：高光一片白
改进：降低曝光补偿，避开直射强灯

问题：颜色很乱
改进：避开彩色杂光，找单一主光源
```

---

## 18.5 练习任务

```text
任务一：夜晚用 28mm、50mm、100mm 各拍一张，看哪个最稳。
任务二：找一个有灯光的背景拍人像，让脸靠近光源。
任务三：用 1s 到 5s 拍车灯光轨，观察三脚架的重要性。
```

# 第十九章 照片整理和后期入门

后期不是把烂照片变神图，而是把已经不错的照片整理得更舒服。

新手先记一句话：

```text
先拍清楚，再谈后期；先调基础，再谈风格。
```

---

## 19.1 为什么要整理照片

如果每次拍完都不整理，你很难知道自己进步在哪里。

建议每次拍完做三件事：

```text
删除明显失败的
选出喜欢的
给好照片做简单调整
```

明显失败包括：

```text
严重糊
对焦完全错
表情闭眼
构图明显失败
重复照片里较差的一张
```

---

## 19.2 怎么挑照片

挑照片不要只看缩略图。

顺序：

```text
1. 先看是否清楚
2. 再看表情和瞬间
3. 再看光线
4. 再看构图
5. 最后看颜色
```

人像挑片优先级：

```text
眼睛清楚
表情自然
光线舒服
背景干净
姿态好看
```

---

## 19.3 后期先调什么

新手后期先只调基础项。

```text
曝光：整体亮暗
高光：压回太亮的部分
阴影：提亮暗部
白平衡：调整冷暖和偏色
裁剪：修正构图和地平线
对比度：增强或减弱明暗关系
饱和度/自然饱和度：控制颜色浓淡
```

建议顺序：

```text
先裁剪和校正水平
再调曝光
再调高光和阴影
再调白平衡
最后轻微调颜色
```

---

## 19.4 RAW 后期基本思路

RAW 的优势是后期空间更大。

适合修：

```text
白平衡偏黄或偏蓝
照片略暗
高光略亮
阴影需要提一点
颜色想更统一
```

RAW 不是万能的。

```text
严重拍糊救不回来
严重过曝到纯白也很难救
对焦错了也很难救
```

所以拍摄时仍然要尽量拍好。

---

## 19.5 新手后期不要过度

常见过度后期：

```text
饱和度太高
皮肤磨得没有质感
对比太强
锐化过度
暗部提太亮导致画面灰
滤镜太重
```

新手建议：

```text
少量调整
肤色自然
颜色统一
保留真实质感
不要每张都套很重的滤镜
```

# 第二十章 最终速查清单

这一章是整本笔记的最终速查。

如果你出门前只想看一页，就看这一章。

---

## 20.1 出门前检查

```text
电池有电
存储卡有空间
镜头干净
模式 A 档
ISO Auto
AF-C
人眼识别开启
白平衡 AWB
RAW + JPEG
曝光补偿回到 0
```

---

## 20.2 拍摄中检查

```text
主体是什么？
光从哪里来？
背景干净吗？
焦点在眼睛或主体上吗？
快门够快吗？
ISO 升高能接受吗？
画面边缘有没有杂物？
```

---

## 20.3 场景参数速查

```text
日常万能：A 档 / F4-F5.6 / Auto ISO / AF-C
半身人像：A 档 / 85-135mm / 最大光圈或 F4 / 人眼对焦
全身人像：A 档 / 50-100mm / 最大光圈到 F5.6
环境人像：A 档 / 28-50mm / F4-F8
风景旅行：A 档 / 28-50mm / F8
街拍抓拍：A 档 / 35-70mm / F4-F8 / 1/250s 以上
室内食物：A 档 / 50-100mm / 最大光圈到 F4 / 窗边侧光
夜景手持：A 档 / 28-50mm / 最大光圈 / Auto ISO
舞台远处：A 档或 S 档 / 150-200mm / 1/400s 以上
运动小孩：S 档 / 1/500s 到 1/1000s / AF-C 跟踪
```

---

## 20.4 失败问题速查

```text
照片糊：提高快门
对焦错：确认焦点框，拍人对眼睛
背景乱：换角度，靠近，用长焦
背景不虚：大光圈，长焦，主体近，背景远
人脸暗：加曝光补偿，让脸朝向光
颜色怪：检查白平衡和光源
噪点多：正常，先保证清楚
画面平：找侧光，强化主体
照片没重点：先问主体是什么
```

---

## 20.5 最终练习建议

接下来不要急着学更多术语，先拍。

建议你做三轮练习：

```text
第一轮：7 天基础练习
第二轮：14 天进阶练习
第三轮：每周一个专题，人像、旅行、室内、夜景轮流练
```

每次只复盘 6 张照片：

```text
3 张喜欢的
3 张不满意的
```

每张只写一句话：

```text
好在哪里？
问题在哪里？
下次只改哪一点？
```

最终目标不是记住所有参数，而是形成直觉：

```text
看到人：想到眼睛、光线、背景、85-135mm
看到风景：想到 F8、地平线、层次、好光线
看到夜景：想到找光、稳住、接受 ISO
看到运动：想到快门、AF-C、连拍
```
