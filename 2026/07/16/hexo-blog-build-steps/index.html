二十、常见问题

1. 页面没有更新

先确认本地是否生成成功：

如果本地正常，再确认是否已经推送：

然后到 GitHub 仓库的 Actions 页面查看部署任务是否成功。

2. GitHub Pages 打开是 404

检查几个地方：

  • 仓库名是否是 用户名.github.io
  • GitHub Pages 是否设置为 main 分支 /root
  • Actions 是否成功推送了 main 分支
  • _config.yml 中的 url 是否正确

3. 图片不显示

如果是文章同名文件夹里的图片，确认：
